# {{ $frontmatter.title }}

玄功門丹青羅剎閻羅生，曾與飛天門[丹霞子](special404)，鐵拳門「白眉虎」[孟瞋](other1)，奪魄門[第三香](special820)，四人並稱崆峒四秀。練就判官筆，有望角逐掌派人之位。
<br><br>
自知實力比不過第三香，便玩物喪志，深信書畫之中隱藏絕世武功。越近掌派人大選之期，就越是廢寢忘食的鑽研書畫。
<br><br>
崆峒歷來由下任掌派人一併迎娶「崆峒四姝」（梅蘭竹菊）以制衡四門，玄功門嫡傳女弟子[呼延菊](special822)與第三香的未婚妻[夏侯蘭](girl5)，都被視作隨掌派人之位一同到手的「戰利品」。豈料大選在即，第三香與呼延菊私訂鴛盟之事，因[虞小梅](girl3)設計而被夏侯蘭撞破，夏侯蘭又哭又鬧，醜事遂傳遍山中。

<br>

旁人只道少年英雄三妻四妾乃人之常情，唯獨比試未開、獎品先被人染指的閻羅生動了真怒。混亂之中，他揮出的判官筆襲向夏侯蘭，由呼延菊以身擋下而香消玉殞；閻羅生自己則被第三香勾出腸子而死。事後第三香與夏侯蘭被掌派人制服，關押於奪魄峰。
