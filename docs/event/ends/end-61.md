## 條件與流程
1. 照[〈虞小梅結緣攻略〉](/event/pursuit/girl3)或[〈郁竹結緣攻略〉](/event/pursuit/girl6)進行到第三年五月上旬崆峒爭奪戰，戰後在崆峒閒晃時：
   + 探望小竹，選擇**📖「我有得選？」**；或
   + 探望小梅，選擇**📖「當然，妳可以去任何想去的地方」**。
2. 辭別崆峒時選擇**📖「接任崆峒掌派人」**，進入結局。
