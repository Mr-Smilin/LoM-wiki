# {{ $frontmatter.title }}

<EndBackground no=65 title="崆峒掌派人">
唐門熄燈那日，你便收起了鋒芒，人在江湖，心卻<br>
不在。<br>
在你治下，崆峒派漸漸淡出武林紛爭，路遇不平，<br>
明哲保身。<br>
不再多管閒事，雖然尚武，卻不是俠──武俠不在<br>
崆峒。<br>
</EndBackground>

## 條件與流程
1. 第三年十二月上旬[「武林盟對策」](/event/simple/3-12-1-武林盟對策#退隱江湖)決定退隱江湖，進入[「告別唐門」](/event/simple/3-12-1-告別唐門)。
2. 符合以下任一種：
   + 與<Girl3Icon>虞小梅</Girl3Icon>結緣，在[伙房](/event/simple/3-12-1-告別唐門#伙房)選擇**📖「去崆峒」**，接著小梅提議投靠金國時選擇**📖「不行」**。
   + 與<Girl6Icon>郁竹</Girl6Icon>結緣，在[鍛冶場](/event/simple/3-12-1-告別唐門#鍛冶場)選擇**📖「去崆峒」**。
3. 點[大門](/event/simple/3-12-1-告別唐門#大門)，進入結局。
