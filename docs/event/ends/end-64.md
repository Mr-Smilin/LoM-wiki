## 條件與流程
1. 與<Girl3Icon>虞小梅</Girl3Icon>結緣（見[〈虞小梅結緣攻略〉](/event/pursuit/girl3)）。
2. 第三年十二月上旬[「武林盟對策」](/event/simple/3-12-1-武林盟對策#退隱江湖)決定退隱江湖，進入[「告別唐門」](/event/simple/3-12-1-告別唐門)。
3. 在[伙房](/event/simple/3-12-1-告別唐門#伙房)小梅問要不要去崆峒時，選擇**📖「去崆峒」**；接著小梅提議率崆峒投靠金國，選擇**📖「可以」**（道德-3）。
4. 點[大門](/event/simple/3-12-1-告別唐門#大門)，進入結局。

## 備註

- 結局中後人鑄了你的銅像，路過的人天天搧巴掌，如同岳王廟前的秦檜跪像。
