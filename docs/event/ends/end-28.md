## 條件與流程
1. 與<Girl6Icon>郁竹</Girl6Icon>結緣（見[〈郁竹結緣攻略〉](/event/pursuit/girl6)）。
2. 第三年十二月上旬[「武林盟對策」](/event/simple/3-12-1-武林盟對策#退隱江湖)決定退隱江湖，進入[「告別唐門」](/event/simple/3-12-1-告別唐門)。
3. 在[鍛冶場](/event/simple/3-12-1-告別唐門#鍛冶場)郁竹說起退隱時，選擇**📖「不了，感覺江湖沒什麼意思了。」**（沒去鍛冶場也一樣）。
4. 點[大門](/event/simple/3-12-1-告別唐門#大門)，道德≦40，進入結局。
