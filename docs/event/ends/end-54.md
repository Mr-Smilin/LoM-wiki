## 條件
[「雲裳結緣」](/event/simple/3-05-1-雲裳結緣)的子事件[「九轉療傷」](/event/simple/3-05-1-九轉療傷)時，對戰異種真氣四連戰，輸掉任何一場。<br>

## 流程
- [收留葉氏兄妹](/event/simple/1-08-1-葉氏行蹤風波)。<br>
- 第二年二月上旬，不[留學崆峒](/event/simple/2-02-1-留學討論)。<br>
- 第二年六月上旬，[離家出走住破廟](/event/simple/2-06-1-離家出走)。<br>
- 第二年八月中旬觸發[留學青城](/event/simple/2-08-2-唐門迎敵)。<br>
- 第二年十二月上旬[「葉雲舟歸來」](/event/simple/2-12-1-葉雲舟歸來)時，有觸發🚩聽說寂滅三摩地。<br>
- 第三年一月上旬[「葉氏兄妹離去」](/event/simple/3-01-1-葉氏兄妹離去)時，讓葉雲裳留在唐門。<br>
- 第三年五月上旬[「師妹招親後半」](/event/simple/3-05-1-師妹招親後半)時，有滿足🚩雲裳結緣前置，以進入[「雲裳結緣」](/event/simple/3-05-1-雲裳結緣)系列事件。<br>
- [「雲裳訣別」](/event/simple/3-05-1-雲裳訣別)時，選擇三次👉「軟性對策」。<br>
- [「九轉療傷」](/event/simple/3-05-1-九轉療傷)時，任何一場對戰落敗即可。<br>
