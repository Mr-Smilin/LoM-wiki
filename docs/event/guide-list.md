## 簡介
- 本條目收集指引遊戲劇情走向的攻略。
- 此類攻略著重劇情分歧路線的指引，而非事件的詳細流程，且攻略內容可跨越事件。
- 單一事件的詳細流程，請見[「事件列表」](/event/story-simple-table)條目。
