# {{ $frontmatter.title }}

[[葉雲舟]]、[[葉雲裳]]兄妹的曾祖，是抗金名將武穆王[岳飛](https://zh.wikipedia.org/zh-tw/%E5%B2%B3%E9%A3%9B)之子岳雲手下的得力大將之一。

<br>

相傳高宗連下十二道金牌，岳飛為全忠義，自甘赴死，惟嘆抗金大業未竟，若兵權被奸佞所奪，大宋勢將無力回天，故將岳家軍主力支散，並藏寶於山中，鑄鐵兵符（用以證明統兵之權的信物，如虎符一般須兩相驗合方能號令三軍）交由長子岳雲保管，以期未來能執兵符號令舊部，繼承護國之志。

<br>

豈料岳雲竟先於其父身死，危難之中託付兵符於部屬，囑其遁隱江湖，靜待武穆後人來取。那名部屬（葉家曾祖）就此隱姓埋名，遁世隱居山林，代代死守兵符——為此，葉家甚至放棄了自己原本的姓氏，改以「葉雲」為姓，以紀念曾祖所侍之主岳雲；就連傳家寶劍「聽雲」，也是「聽從岳雲」之意。

## 一族的分裂：野利察漢

並非所有岳家軍舊部後裔都選擇死守誓言。[[李元棄]]（原名野利察漢）的祖上一脈，同為岳家軍舊部之後，卻在岳飛遇害後心灰意冷，為了報仇雪恨，叛離軍隊投靠西夏。這一支後來成為[[極樂教]]左使，在[[決戰極樂教]]中擊敗青城[[趙逵]]後身受重傷，帶著信物到葉家欲相認，卻遭拒絕，只得奉還祖傳的聽雲劍，就此在葉家附近養傷。

<br>

養傷期間，他曾勸葉家放下這樁延續三代的執念：岳元帥早已死了，是被大宋官家下令殺死的；葉家對大宋盡忠早已足夠，盲目的愚忠不是忠，只是愚，不該讓一個執念囚禁後世子孫。然而葉家不肯接受他「落葉歸根」的請求，他這才心灰意冷，索性化名「李元棄」——「李」姓取自西夏王姓，「元棄」意即斬斷親緣、拋棄過去。

## 秘密現世，以及葉雲裳本人的說法

江湖上一直流傳著一種說法：這個守了將近百年的秘密終究走漏了風聲，寶藏與兵符引來了滅門之災，[[葉雲裳]]的父母唯恐兵符落入賊子之手、導致生靈塗炭，遂將兵符烙印在愛女背上後，親手毀棄兵符本體。

<br>

但據[[葉雲裳]]本人所言，這個「寶藏」的說法並不準確。真正引來滅門之禍的，其實是[[白風峒變亂]]戰事最激烈時，父親一時心急所寫的一封密信。[[李元棄]]起事後，四路廂兵久攻不下，中原動盪，父親痛心疾首，遂密信上奏朝廷，舉發族叔[[李元棄]]，意圖使其身敗名裂、喪失民心；信中甚至自稱「不肖子孫，有愧皇恩」，欲藉此撇清葉家。

<br>

豈料弄巧成拙——官家讀信後龍顏大怒，反而認定葉家是一丘之貉的亂臣賊子，既然拿不住[[李元棄]]，便派兵直撲葉家，意圖挾持全家，逼反賊投鼠忌器。官兵來勢洶洶，不由分說，父親不甘受此汙名，強抗而死；母親悲痛欲絕，撞柱殉夫；[[葉雲裳]]本人也中了一掌，經脈寸斷，奄奄一息，此後十幾年都要死不活。[[葉雲舟]]、[[葉雲裳]]兄妹自此淪為孤兒。事後官家唯恐落人口實、被譏為殘害忠良，反倒竭力遮掩此事，葉家忠良之名因此得以保全。

<br>

「愚忠才是滅門的真相，壓根無關什麼岳王寶藏」——這是[[葉雲裳]]本人對這樁公案的總結。

## 李元棄的贖罪

慘案當夜，[[李元棄]]便孤身出軍營，尋來已經奄奄一息的[[葉雲裳]]。他先問她願不願意活下去——若救她，爹娘的冤屈便討不回來；若她甘願捐軀明志，他則發誓終有一日要讓昏君到岳元帥與她爹娘墓前磕頭謝罪。年幼的[[葉雲裳]]答說願以一死明志，[[李元棄]]聽罷非但沒有稱許，反而斥她沒把道理聽進去，仍舊喂她服下了苦心煉製的「九泉丹」——比起虛無縹緲的忠義，性命更該珍惜；旁人的執念，不該由這一代人扛。

<br>

這粒丹藥對[[李元棄]]而言代價不小：據傳九泉丹不僅能起死回生，還可增長十年功力，若他自己服下，兼修九轉輪迴、吞天寶鑑，恐怕當年連[[唐布衣]]等人也未必是對手；他卻將這救命的機緣用在了一個「不相干」的姪女身上。

<br>

後來，流離失所的葉家兄妹一度南下湖南，想投靠[[李元棄]]，卻被他毫不留情地掃地出門，連面都不見——實際上是怕再牽連他們，欲保全葉家忠良之名。

<br>

最後，[[李元棄]]敗於[[唐布衣]]等五人之手，殞命於白風峒變亂的尾聲。
