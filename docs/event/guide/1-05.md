# {{ $frontmatter.title }}

## 上旬
- 開始導入門派貢獻制度，雖然低貢獻不影響主線劇情，但高貢獻通常有更好的數值變化，且後續影響設施開啟，建議常態保持在80以上
- 四師兄自動引進彈珠台，彈珠台的部分獎勵不錯，詳細可以參考[此處](/system/pinball#四師兄兜售)

## 中旬
- 無重要事件

## 下旬
- 段考事件開始，一共四次，第一次難度很低，通常一定會過，後續難度遞增，雖不影響主線，但對數值有不錯加成
- 第一次打輸會強制遊戲結束，獲得生死簿10「小師妹的制裁」，其他時候打輸就是下一次段考重複對手
