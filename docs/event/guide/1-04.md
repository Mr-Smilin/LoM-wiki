# {{ $frontmatter.title }}

## 上旬
### 1.遊戲開局
- 簡單介紹世界觀，這裡的事件不影響後續內容
- 第一晚照鏡子時若選擇「還不算差」，趙活立繪會稍微好看一些，並取得技能「自戀」

### 2.初入設施與遊戲教學
- 五月結束前，女弟子房、煉丹房、伙房、練功場、男弟子房、講經堂初次進入都會有些事件影響數值，可以善加利用
- 初入伙房若觸發【≧95】嚇死會達成生死簿7「屁力焦蛙」
- 心相憂鬱時進入男弟子房，觸發「琴棋書畫」並選擇「啊，我好像懂」，會獲得道具「大師兄的塗鴉」，後續在郁竹相關事件可取得「逆鱗寶衣」，此訊息待考證
- 後山砍柴有機率觸發推人劇情，但目前仍未確認後續變化
- 五月結束前於大門的鬧市隨機刷出「包袱被割」後續可觸發[「偷懶怪」](/event/simple/1-04-1-偷懶怪)相關事件，詳見連結


## 中旬
- 自動觸發主線劇情，事件最後送的秘笈雖然後期都買的到，但對初期戰力有巨大影響
- 五毒秘錄能降低達成醫術5的難度，但不是必備，可斟酌獲取

## 下旬
- 四師兄好感15以上會觸發葉氏兄妹相關劇情，此事件與其後續劇情可獲得大量金錢，且能開啟葉雲裳結緣可能，建議觸發
- 葉氏兄妹劇情根據選擇變化，對初學者來說戰鬥難度可能過高，建議先行存檔
