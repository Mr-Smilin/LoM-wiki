# {{ $frontmatter.title }}

## 上旬
- 自動觸發南宮壽宴討論，此為第一個跨月份大型主線劇情
- 若選擇「(小師妹好像欲言又止？)」，小師妹會參加壽宴，但對主線影響不大
- 若觸發「獻靈丹」，會強制一回合只能去煉丹房，但會看到屍心丹相關劇情
- 若觸發「耕陽讀書齋墨寶」，根據江湖快報數量提升貢獻
- 若觸發「幹掉仇人」，會提早出發，此路線難度較高，不適合初學者

## 中旬
- 若壽宴討論時觸發「幹掉仇人」，此時會強制出發，建議上旬時把錢花光且心相拉到80以上，對數值變化比較有利

## 下旬
- 無特殊劇情，先行出發參加壽宴會跳過此時間
