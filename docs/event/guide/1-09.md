# {{ $frontmatter.title }}

## 上旬
### 初識龍湘
- 九月上旬自動觸發，建議提早進行存檔
- 建議烤雞，沒為啥，不吃雞的湘姐就不是湘姐了
- 若選擇幫助公子俠，打輸觸發生死簿47「為虎作倀」
- 石灰粉解除條件如下，達成其一即可：
	1.江湖鬼蜮錄LV1
	2.醫術LV1
	3.煉丹獲得點數（不算開局加成）>30
- 若趙活擋了石灰粉，沒成功解除會觸發汗青書17《盲劍客》
- 理論上，無論有沒有解除石灰粉、有沒有烤雞、有沒有姐弟相稱，都不影響結緣，待考證

### 唐芳歸來
- 葉氏兄妹入住唐門才會觸發，否則唐芳會一路失蹤到遊戲結束
- 撿行李時觸發「五成，聊勝於無」，會獲得秘笈《難經》，是少數無法購買的醫書，對提升醫術幫助很大

## 中旬
### 龍湘相關事件
- 四師兄好感5以上會觸發公差事件，門檻很低，不太可能不觸發，若初識沒解除石灰粉又沒觸發此事件，高機率斷絕龍湘結緣可能，待驗證
- 觸發公差事件後下山，隨機觸發龍湘遭竊事件，不影響主線，可不觸發
- 龍湘遭竊事件若察覺偷錢且追上，打輸會觸發生死簿85「被蛇咬死」

### 結交丐幫與嵩山派
- 晁和入門後男弟子房隨機觸發勸架事件，事件結束後開啟結識可能，一路睡過去不算
- 勸架事件後下山會觸發結識事件，第一次結識李富貴與樊嘯天，第二次結識福韞
- 結識福韞事件若觸發揍福韞且後續買不起又硬搶秘笈，黑吃黑打輸會觸發生死簿87「黑吃黑失敗」
- 結識福韞事件中，幫助或旁觀都會導致許大鯨加入唐門，對團戰有幫助
- 其實不結交三人也沒關係，但對初學者而言，結交比較方便觸發武林傳奇結局，後續劇情也會相對有趣一些

### 其他
- 若葉氏兄妹入住且唐芳已歸，會觸發下山遊玩事件，跟主線無太大關係，但隱藏了一段上官螢的彩蛋劇情，需要上官螢入住才能觸發，因此觸發難度極高

## 下旬
