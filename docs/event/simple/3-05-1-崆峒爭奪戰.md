## 事件時間

## 觸發條件
要從[「對決金烏」](/event/simple/3-05-1-對決金烏)進入本事件，需要的條件概念上可歸納為:
- 郁城求助: 認識郁家人，且郁城認可趙活實力。
- 趙活動機: 知道虞小梅身分，且有幫助<Girl3Icon>虞小梅</Girl3Icon>或<Girl6Icon>郁竹</Girl6Icon>的動機。

根據以上概念，具體條件歸納如下:
- 曾觸發[「郁竹返家」](/event/simple/2-04-2-郁竹返家)事件(認識郁家人)。
- 若🚩[臥雲崗事件留守山上](/event/simple/3-01-2-臥雲崗事件)，需[觸發治療大師兄劇情](/event/detailed_description/4-02-2-飛俠歸來)，但治療結果不影響(知道虞小梅身分)。
- [「對決金烏」](/event/simple/3-05-1-對決金烏)時，初戰必須勝利，且若未[見過金烏上人詐死](/people/characters/special207_death#見過金烏詐死)，需成功迴避金烏偷襲(郁城認可趙活實力)。
- 小師妹及瑞笙都不可在場，因為在場表示心上人為<Girl0Icon>唐默鈴</Girl0Icon>，會優先帶她回唐門(趙活動機)。
- 郁城請求協助後，滿足以下任一條件(趙活動機):
  1. 心上人為虞小梅，且曾🚩[經歷襄陽行](/event/simple/2-10-1-失戀歸途#接受處置)。
  2. 心上人為郁竹，且曾🚩[收留郁竹](/event/simple/2-10-2-郁竹拜師#郁竹拜師)。
- 回應郁城請求時，選擇👉「我得去」，即可進入本事件。
