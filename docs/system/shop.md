# {{ $frontmatter.title }}

## 簡介 {#簡介}

- [唐惟元](/people/characters/brother4)(四師兄)的商店，賣秘笈、酒、茶、食物、色紙和江湖快報。
- 每月上旬換貨，數量也在這時補滿。
- 已經有的秘笈不會再上架。
- 買了茶、酒、食物可以當場吃，見[關於四師兄商店](/other/guide/mechanism/brother4-selling)。

## 入口 {#入口}

1. [四師兄閒聊](/event/simple/0-0-0-四師兄閒聊)：到男弟子房找四師兄閒聊，選「買賣物品」。四師兄不在唐門的期間找不到他。
2. [四師兄遠遊經商](/event/detailed_description/3-08-1-四師兄遠遊經商)：第三年八月上旬的唐門會議選「故意提出一些難辦的要求」，轉盤骰到【＜70】感恩酬賓大回饋時開店，商品半價。
3. 崆峒留學：到[無色市集](/people/factions/kong-tong-sect#無色市集)逛街，有機會碰到四師兄。唐惟元好感≥20 時比較容易碰到。
4. [四師兄訪青城](/event/simple/2-10-1-四師兄訪青城)：青城留學線，第二年十月上旬唐惟元好感≥30 時觸發，選「買」。
5. [江陵圍城](/event/simple/2-09-1-江陵圍城)：自由行動選「四師兄(商店)」。

## 價格 {#價格}

- 買價＝原價×(1－唐惟元好感÷200)，四捨五入。好感每 1 點便宜 0.5%，好感 100 時半價。
- 從[四師兄遠遊經商](/event/detailed_description/3-08-1-四師兄遠遊經商)的「感恩酬賓大回饋」進去時，一律半價。
- 每次離開商店時，在商店買賣的累計金額每滿 1000，唐惟元好感+1。想省錢可以分批買：每買滿 1000 就離開再進來，好感先漲，後面買的就更便宜。
- 只有道具能賣給四師兄，賣價是原價的 4 成。秘笈和江湖快報不能賣。
