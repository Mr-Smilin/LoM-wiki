# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="2402"></BookItemIcon>

道法將軍丹霞子的成名絕技，其實並不是一套武功。
<br><br>
崆峒開山立派之初，山中門派林立，崇尚暴力與混沌，尤以天竺「魔僧」鳩摩羅闍、突厥「殺星」執失賀魯為最。
<br><br>
一使熔天魔炎劍，一使吞月蒼狼刀，恰為至陽至陰，威力雖強，但心法偏激，都不是正派武功。
<br><br>
習練者功力越深，性情亦不免越發火爆、陰狠，當年若由此二人中任一位統霸崆峒，立威建國，中土版圖恐怕就不會是今日模樣。
<br><br>
幸有初代掌派橫空出世，滌盪群邪，號召神雷殛毀魔功，崆峒才得以歲歲太平。
<br><br>
兩部魔功殘頁隨風飛舞，散落群山中，及至數百年後，丹霞子意外跌落彈箏湖，經湖洞沿路撿拾殘頁，匯聚成書，竟奇蹟般將兩部魔功合為一部，而且去蕪存菁，陰陽相合，昔日魔典，遂成神功。

## 獲得方式

-   金烏事變前往崆峒的路上選「啟程出發」，若[[丹霞子]]好感≧30，他會把這本書丟進火堆，趙活搶救回來後獲得；好感不足就沒有這段。
    -   小梅線：依襄陽行中孟珙的好感（1~4），[[丹霞子]]好感+3~+12；[[孟仙謠]]好感≧3再+10；崆峒路上的閒聊與切磋最多再+9。
    -   小竹線：因好感度不足，目前無法取得。

## 備註

-   [[丹霞子]]的成名武功。獲得時書的封皮被燒到一點，內頁完好。
-   獲得書後若處世≧60，趙活會道謝，[[丹霞子]]好感+1。
