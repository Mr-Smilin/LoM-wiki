# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="2400"></BookItemIcon>

李白中年將侍於翰林院，封劍退隱之前留下的劍法，一共三十六式。
<br><br>
這套劍法只在弟子武諤面前使過僅僅一次，那時李白還喝醉了。
<br><br>
起似隨興揮灑，偏生處處神來一筆，妙到顛毫，似劍而非劍，破千古窠臼，闢未有之奇。
<br><br>
一套劍法使完，獨立樹梢，衣袂飄飄，宛如神仙。而坐觀的武諤卻全身大汗淋漓。
<br><br>
相傳武諤有艱澀難解處，欲請教師父，李白卻道：「莫問我，問了你便學不會。」武諤猛然頓悟，歡天喜地而去，殊不知李白只是宿醉推搪而已。

-   太白仙跡：境界二以上，絕招變為[太白仙跡]。四回合內，全屬性超幅提升，有50%機率迴避敵人攻擊，四回合後氣歸零。捅人指令變為「舞劍」，造成1~3段傷害。連擊數>10時，立即追加超強大傷害，並解除太白仙跡狀態。

## 獲得方式

-   [瑞笙來訪](/event/simple/4-02-1-瑞笙來訪)－瑞笙好感≧40時，在最後選「爭鬥的理由」（需先聊過「你怎麼變的盟主？」）聊到道別時，由[[瑞笙]]贈送。好感＜40則不會贈送。
