# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="`6014`" />

峨嵋拳法，有別於後世所傳的醉拳套路，這套拳譜並無固定套路，卻有八種架式，可以隨意組合，令人摸不清頭腦。開篇歌訣云：「撇步推肩臂如猿，擠身頓肘爪勝鞭，手腦爭快腳蹣跚，此去無方浪流連。」了道盡這部拳法的精隨。
<br><br>
既是醉拳，當然是喝個爛醉再練。

## 效果

需求：身上有黃酒 或 形意拳LV1

每次修練消耗 1 個黃酒（有形意拳LV1 就不需要黃酒），用「下一級」按鈕一次升一級也只消耗 1 個，只靠黃酒的話練滿最少要 10 個。
