# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="`6011`" />

與奪魄《鎮魂功》、鐵拳《傷拳》、玄功《鐵琵琶功》同出《南嶽真經》的飛天門失傳神通。
<br><br>
飛天腳、仙鶴迷蹤步的原始之型。
<br><br>
功成者可以一趾立地，無須屈膝使力，僅憑內力驅使，便能滑行疾飆。出腳時勁由身通腿，腿通腳，腳通趾，將萬鈞威力收束於一點，視乎意念，可剛可柔，剛能一趾點破金鐘罩，柔能以趾勁封人穴道。
