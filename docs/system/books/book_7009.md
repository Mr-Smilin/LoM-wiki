# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="7009"></BookItemIcon>

飛天門和奪魄門角逐崆峒門面之選，為求速成，不惜飲鴆止渴，以火蠍毒助長內力，強行突破瓶頸。
<br><br>
運使焚心火印，能夠暫時加速心搏，推動血流、以燃燒餘壽為代價，全面提升肉體能力。
<br><br>
但是代價不只這些，火毒囤積在體內，每達鼎盛就會溢於表徵，輕則口乾舌燥、牙齦滲血、失眠易怒，重則火氣沖腦，不是痴呆就是暴斃。
<br><br>
每年端午陽氣最盛之時尤為兇險，不可不慎。

## 獲得方式

-   二年崆峒派留學－飛天門[[崆峒季試]]三勝獎勵([[虞小梅]]好感 ≧20)
-   🚧 三年招親－留學飛天門，打贏[[金烏上人]]，[[顏疆]]死亡時贈送：劇本有這段，但目前版本的判斷條件設錯，實際只會拿到[[仙鶴迷蹤拳]]。

## 備註

-   飛天門的奧義。
-   焚心火印本來光明正大，若能平心靜氣按部就班習練，吸納暑氣，鍛鍊臟腑，日久自能功成。
-   因飛天奪魄兩門鬥爭激烈，飛天門前輩創出速成法門，服火蠍毒強行催谷熱力，煎熬臟腑，若能熬過大關不死，便能功成。
-   但以此法門習練的弟子，十有八九短命早死。
-   若[[玄燭心經]]完畢修練，即便焚心火印屬性為陽仍會失效。

### 虞小梅劇情關聯

-   若[[趙活]]在飛天門季試獲得焚心火印，小梅會奉勸不要修練焚心火印，並告知其風險&代價，及[[火龍仙君]]的真實目的。
-   小梅天賦異稟，沒有暴斃即死，再得[[火龍仙君]]運功疏導火力，終於功成圓滿。
    -   只是臟腑既傷，後患無窮，每回運功也必心焦如焚，劇痛難當，遠則折壽，近則有暴斃之危，壓根不能實戰，是以[[虞小梅|小梅]]與人交手，也從來不催運焚心火印。
    -   在刺殺唐布衣事件中，小梅/女飛賊對付[[趙活]]時，難得催運焚心火印作為實戰。
    -   小梅修練焚心火印，除了有快速提升功力的目的外，也有指望焚心火印能消滅屍心丹的毒蟲，可惜後者並未成真。
    -   拜訪錦香宮期間，[[畫中仙]]冒着風險私下贈予[[玄燭心經]]，盼小梅抵消火蠍毒。
-   掌派爭奪戰期間，小梅試圖在半雨屏對山高處樹上，催運焚心火印，配合烈焰飛天腳飛躍而下，和[[金烏上人]]同歸於盡。
    -   不料行動遭奪魄掌門阻止，心智遭屍心丹控制。
