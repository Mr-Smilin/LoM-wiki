## 忘形篇
> 『形而上者謂之道，形而下者謂之器，無器則道無從顯，非器則道無所寓。<br>惟聖人可以踐形，萬化皆從方寸發，萬物皆備於我。』

- 開篇《忘形論》（也叫忘形篇）講萬物皆可作暗器、不必拘泥外形。
    - 秘笈其餘的手法、心訣要師長傳授，外姓弟子學不到，[[趙活]]只讀得懂這一篇，背得滾瓜爛熟。
    - [[唐門]]暗器歌訣：『天下無指，器無可以謂器。非指者，天下無器，可謂指乎？指器者器之，天下無不器。』
- [[蒙面人開導]]：後山的[[唐布衣|蒙面人]]點撥[[趙活]]，照忘形論的道理，各派武功都能當暗器練，使的仍是唐門武功。
- 與忘形論同理的武學：[[唐布衣]]閉關悟出的「無形之型」、[[向無憂]]的「無形拳」，以及唐布衣在[[圍觀臥雲崗|臥雲崗]]使的[[擲石問天]]。
- [[趙活]]指導[[唐衫]]武學技巧時，特別背誦忘形篇提示其內核。
