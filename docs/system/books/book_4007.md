# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="4007"></BookItemIcon>

姿態優美，宛如畫中美人躍出紙面，一顰一笑皆牽人心魄，乍看之下柔弱無力，其實每個舉動都蘊含著精妙的後著，拿人穴道於言笑晏晏之間，既不快，也不狠，但就是教人無從閃避，百發百中。
<br><br>
不過被閣下的尊容中和後，命中率至少減半。

-   點穴：攻擊命中時，造成麻痺累積（LV1 10點、LV2 15點、LV3 20點）。
-   折花手：備揍時，有機率接住暗器（LV1 5%、LV2 10%）。若接暗器成功，造成對手追加「膽怯」。

## 獲得方式

-   小竹回家－抵達老虎山下的鎮子，等小竹梳洗換裝時，選「有個雜貨地攤」（只能選一次）。需修養≧40，攤販才肯做生意。
-   與攤販交談後天命擲骰，擲到「武功秘籍」（70~84）時，攤販以3000銀兩兜售，銀兩≧3000並選「買」後獲得。

## 備註

-   攤販稱這本秘笈是他叔叔練的武功，叔叔練完後被人打死了。
