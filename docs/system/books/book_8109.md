## 獲得方式

需完成以下所有條件：<br>
1. 曾🚩[留學青城](/event/simple/2-08-2-唐門迎敵)。
2. 二年十二月上[葉雲舟歸來](/event/simple/2-12-1-葉雲舟歸來)時，葉雲裳好感≥30且技能《醫術》≥3，以觸發🚩「聽說寂滅三摩地」。
3. 三年一月上[葉氏兄妹離去](/event/simple/3-01-1-葉氏兄妹離去)時，心上人是葉雲裳，兄妹爭論時擲骰到【🎲≥80 葉雲裳抵抗】，再選擇👉「勸葉雲舟留」。
4. 滿足以上，則[葉氏兄妹離去](/event/simple/3-01-1-葉氏兄妹離去)最後，會由唐芳贈送此秘笈。
