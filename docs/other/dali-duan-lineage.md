# 大理段氏世系 (遊戲設定)

整理[葉雲裳](/people/characters/girl2)在說明[段智秀](/people/characters/special833)來歷時，
所講述的大理國 ([點蒼派](/people/factions/dian-cang-sect)所在地) 段氏皇室世系。
青城留學期間的事件[雲裳商議](/event/simple/2-10-2-雲裳商議)中，閒聊「松煙閣的少爺」→ 選「完整版」，
雲裳會花上大半個時辰畫出世系譜表，從開國太祖一路講到段智秀的政變。
選「一言以蔽之」則只有摘要，看不到這張世系譜。

遊戲中的大理國幾乎照搬史實的大理國 (937〜1254 年，今雲南)。
廟號、諡號、退位經過、高氏專權都與史實相符，虛構的部分集中在與[段智秀](/people/characters/special833)相關的情節，
以及與點蒼派的連結。與史實不同之處記於「與史實的對應」欄。

::: warning
包含[葉雲裳](/people/characters/girl2)線 (青城留學) 中段智秀身世的劇透。
:::

## 雲裳所述的世系

「支系」依雲裳的說法：開國之君段思平的直系為第一支系，其弟段思良一脈為第二支系，
兩支系輪替爭奪帝位長達百餘年，是整段敘述的骨幹。

## 松煙閣與段智秀

點蒼派的藏經閣是後山古老的「松雲閣」；[段智秀](/people/characters/special833)負責的「松煙閣」則是憲宗派人興建的閣樓，
座落於視野最好的高峰之上，可以一覽蒼山景觀，同時也能監視點蒼派。
點蒼山與大理城之間「要不是有城牆和守衛，散個步就能走進皇宮」，一群武林高手住在隔壁，大理皇室不可能不在意。

其後，被憲宗打壓多年的高氏權臣找到第二支系的末裔——天明帝段素興的七世孫、年僅五歲的段智秀——把他拱出來發動政變，以失敗告終。
先帝隨其父皇崇佛、不願多造殺業，沒有取幼小的段智秀性命，只廢去世子之位、褫奪忠國公府的襲爵權，將他流放到點蒼派，也有作為人質、藉此籠絡點蒼的用意。
掌管松煙閣的身分「既高且低」，就是由此而來。

「段素興七世孫段智秀」與這場政變是遊戲虛構。史實中段智興之後由其子段智廉 (1200〜1204 年)、段智祥 (1204〜1238 年) 繼位。

## 與金庸作品的關係

遊戲中的大理段氏除了史實，也以金庸《天龍八部》為底本。此處只列出可確認出處的部分。

- 「天龍寺」是《天龍八部》給史實崇聖寺取的名字，本作沿用。
- 段智秀所用的[枯榮神功](/system/books/book_7017)，名稱源自該書中段思平所創、天龍寺枯榮大師修習的段氏內功「枯榮禪功」。
- 憲宗段和譽 (段正嚴) 是《天龍八部》段譽的原型，宣宗段智興是《射鵰英雄傳》一燈大師的原型。

將段和譽的「無形劍氣」與六脈神劍連結是很自然的讀法，但本作並無明示，故不下定論。
