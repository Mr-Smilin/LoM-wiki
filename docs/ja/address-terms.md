# 呼称表 — 誰が誰を何と呼ぶか

::: info
本ページは台詞データから呼びかけ (vocative) として実際に使われた呼称を機械抽出し、
場面文脈による話者・相手の判定と人力レビューを経てまとめたものです (2026-07-31 再構築、2026-10-23 に大型更新で増えた台詞を追加し、話者をゲームの台本データの話し手に合わせて引き直し)。
誤りに気づいた場合は編集にご協力ください。
:::

儒教文化圏の作品では、誰が誰をどう呼ぶかに身分・年齢・親密度が色濃く反映されます。
師兄・師姉などの序列呼称は**正式な入門順**で決まり、年齢とは無関係です。

- 表記: 呼称は MOD 訳、原語列は繁体字原文で対応が取れたもの (同一表記・対応不明は空欄)
- 相手・場面によって呼び方が変わる場合は回数の多い順に複数掲載しています。回数の多いものが
  基本の呼称で、少ないものは特定の場面・関係の進展に応じた使用です
- 「彼」「あの人」のような三人称言及・代名詞は本表の対象外です (呼びかけのみ収録)
- 出典列は代表的な使用場面のイベントページへのリンクです (順次拡充予定)
