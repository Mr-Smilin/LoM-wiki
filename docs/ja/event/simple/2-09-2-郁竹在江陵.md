# {{ $frontmatter.title }}

## イベントの時期
- 早ければ2年目9月中旬。
- 遅くとも2年目9月下旬。

## 発動条件
- 🚩[留学について](/ja/event/simple/2-02-1-留學討論)。
- 🚩[崆峒派、江陵に到着](/ja/event/simple/2-09-2-崆峒派抵江陵)で「崆峒派が江陵に参戦」を設定済み。
- <Girl6Icon>郁竹</Girl6Icon>好感≥30。
- 以上を満たし、期間内に[南宮家滞在イベント集](/ja/event/simple/2-09-1-南宮作客事件集)の「何もせず涼む」コマンドを選ぶと発動。

## シリーズイベント
- 1件の記事が長くなりすぎるのを避けるため、本イベントはシリーズに分割している:
  1. [郁竹との再会](/ja/event/simple/2-09-2-重逢郁竹)
  2. [虎戦車の組み立て](/ja/event/simple/2-09-2-組裝虎戰車)
  3. [虎戦車の試運転](/ja/event/simple/2-09-2-測試虎戰車)

## 虎戦車の製作
- 本イベントで🚩「虎戦車を製作」が解放される条件は、次のようにまとめられる:
  1. 🚩[虎戦車の図面を入手](/ja/event/simple/2-08-1-神兵鍛成#神兵鍛成)していること。
  2. [「郁竹との再会」](/ja/event/simple/2-09-2-重逢郁竹)を手動で発動すると、[「虎戦車の組み立て」](/ja/event/simple/2-09-2-組裝虎戰車)が自動で発動する。
  3. イベント中のダイスで【🎲 帰って寝る】または【🎲 名前を付ける】が出れば解放される (経路その1)。
  4. イベント中のダイスで【🎲≥80 試運転する】が出た場合は、[「虎戦車の試運転」](/ja/event/simple/2-09-2-測試虎戰車)が自動で発動する。
  5. 虎戦車との対決では、「勝つ、または自軍の体力≤50%にする」と解放されず、「敗れる、または6ラウンド耐える」と解放される。対決終了後に自動で解放される (経路その2)。
