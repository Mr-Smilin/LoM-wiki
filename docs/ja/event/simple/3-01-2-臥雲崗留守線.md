## シリーズイベント
- 本記事は、3年目1月中旬の[臥雲崗イベント](/ja/event/simple/3-01-2-臥雲崗事件)で下山せず唐門に残ることになった場合（🚩「唐門に残る」）に発生するシリーズイベント。
- イベントの多くは自動で発動するが、一部には追加の条件がある。
- 時系列順に並べると次のとおり:
  1. [臥雲崗の留守番](/ja/event/simple/3-01-2-臥雲崗留守)
  2. 兵器の点検
  3. 同門の手伝い (追加の発動条件あり)
  4. 剣閣の来訪
  5. [大師兄の重傷](/ja/event/simple/3-01-3-大師兄重傷)
  6. [裏山埋葬](/ja/event/simple/3-01-3-後山安葬)
