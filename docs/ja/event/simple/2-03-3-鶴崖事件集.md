# {{ $frontmatter.title }}

## 解放条件
- 前提条件: [留学について](/ja/event/simple/2-02-1-留學討論)で崆峒派に留学し、🚩[崆峒派への留学](/ja/event/simple/2-03-1-崆峒留學)で飛天門に入門していること。
- 解放条件: 🚩「鶴崖を開放」が必要。[飛天門のいじめ](/ja/event/simple/2-03-3-飛天門霸凌)で鶴崖へ逃げ込んだとき、または[鎮魂獄での拘留](/ja/event/simple/2-03-3-鎮魂獄羈押#進入鶴崖)で小梅に牢から連れ出されて鶴崖へ逃れたときに立つ。[「小梅との共舞」](#小梅共舞)、[「鶴崖での季試の振り返り」](/ja/event/simple/2-05-3-鶴崖季試檢討)、または[南宮への急援](/ja/event/simple/2-08-1-馳援南宮)で終わる。
- 時期: 早ければ2年目3月下旬。追加の時期制限がある場合は、下表の各イベントの発動条件を参照。

## イベント集

- 各サブイベントは互いに連続しておらず、<MarkdownWrapper>[「火閃電に教えを請う」](#向火閃電討教)</MarkdownWrapper>を除いてすべて1回限りのイベント。発動条件は下表を参照。
- 複数の条件を満たす場合は下表の順で優先され、1回のコマンドで複数のイベントが同時に発生することはない。
