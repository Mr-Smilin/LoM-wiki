# {{ $frontmatter.title }}

## 発生時期
- 開始および主な発生時期は3年目5月上旬。
- 最後の子イベント[崆峒に別れを告げる](/ja/event/simple/3-05-1-辭別崆峒)では、時間が3年目7月中旬に設定される。

## 発動条件
[金烏との決闘](/ja/event/simple/3-05-1-對決金烏)から本イベントへ進むには、大きく分けて次の2点が必要となる:
- 郁城の救援要請: 郁家の面々と面識があり、郁城が趙活の実力を認めていること。
- 趙活の動機: 虞小梅の正体を知っており、<Girl3Icon>虞小梅</Girl3Icon>または<Girl6Icon>郁竹</Girl6Icon>を助ける動機があること。

具体的な条件は以下のとおりである:
- [郁竹の帰郷](/ja/event/simple/2-04-2-郁竹返家)を発生させていること (郁家の面々と面識がある)。
- 🚩[臥雲崗イベント](/ja/event/simple/3-01-2-臥雲崗事件)で山に残った場合は、大師兄の治療イベント ([飛侠の帰還](/ja/event/detailed_description/4-02-2-飛俠歸來)を参照) を発生させていること。治療の成否は問わない (虞小梅の正体を知っている)。
- [金烏との決闘](/ja/event/simple/3-05-1-對決金烏)で初戦に勝利すること。さらに、金烏上人の死んだふりを見ていない ([金烏上人の死](/ja/people/characters/special207_death#見過金烏詐死)を参照) 場合は、金烏の奇襲を回避すること (郁城が趙活の実力を認める)。
- 小師妹と瑞笙のいずれもその場にいないこと。いる場合は想い人が<Girl0Icon>唐黙鈴</Girl0Icon>であるため、彼女を唐門へ連れ帰ることが優先される (趙活の動機)。
- 郁城に助けを求められた後、次のいずれかを満たすこと (趙活の動機):
  1. 想い人が虞小梅であり、かつ🚩襄陽行を経験している ([失恋の帰り道](/ja/event/simple/2-10-1-失戀歸途#接受處置)を参照)。
  2. 想い人が郁竹であり、かつ🚩郁竹を受け入れている ([郁竹を引き取る](/ja/event/simple/2-10-2-郁竹拜師#郁竹拜師)を参照)。
- 郁城の頼みに対して👉「行かなくては」を選ぶと、本イベントへ進む。

## 梅ルートと竹ルートの区別
- 本イベントには梅ルート・竹ルートの区別がある。
- 「崆峒神威」子イベントより前は、以下の2つのフラグで区別する:
  1. 🚩襄陽行を経験: 該当すると梅ルートとなり、想い人が<Girl3Icon>虞小梅</Girl3Icon>に固定される。非該当の場合は竹ルートとなる。
  2. 🚩郁竹を受け入れた: 該当すると竹ルートとなり、想い人が<Girl6Icon>郁竹</Girl6Icon>に固定される。非該当の場合は梅ルートとなる。
- 「崆峒神威」子イベント以降は、🚩「崆峒神威分岐=梅ルート」、🚩「崆峒神威分岐=竹ルート」などで区別する。
- [仲間たちの見舞い](/ja/event/simple/3-05-1-探望眾人)で虞小梅または郁竹と結縁した後は、🚩「虞小梅と結縁」、🚩「郁竹と結縁」で区別する。
