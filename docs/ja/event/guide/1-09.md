# {{ $frontmatter.title }}

## 上旬
### 龍湘との出会い
- 9月上旬に自動で発生するため、事前にセーブしておくのがおすすめ。
- 鶏を焼くのがおすすめ。理由はなくとも、鶏を食べない湘姉は湘姉ではない。
- 公子侠を助ける選択肢を選び、戦闘に敗北すると生死簿47「虎の先棒」に到達する。
- 石灰粉の解除条件は以下のいずれか1つを満たすこと：
  1. 江湖鬼蜮録 LV1
  2. 医術 LV1
  3. 煉丹で獲得したポイント（開始時のボーナスを除く）＞30
- 趙活が石灰粉を庇った際、解除に失敗すると汗青書17《盲目の剣客》に到達する。

### 唐芳の帰還
- 葉氏兄妹が唐門に入居している場合のみ発生し、そうでなければ唐芳はゲーム終了まで行方不明のままになる。
- 荷物を拾う際に「五割、ないよりはまし」を引くと秘笈《難経》を獲得できる。購入できない数少ない医書の1つで、医術を上げるのに大きく役立つ。

## 中旬
### 龍湘関連イベント
- 四師兄の好感度が5以上あると公用外出イベントが発生する（発生条件の詳細は[龍湘結縁攻略](/ja/event/pursuit/girl8)も参照）。
- 公用外出イベント発生後に下山すると、ランダムで「龍湘、盗難に遭う」イベントが発生する。メインストーリーには影響しないため、発生させなくても問題ない。
- 「龍湘、盗難に遭う」イベントでスリに気づいて追いかけ、戦闘に敗北すると生死簿85「毒蛇の牙」に到達する。

### 丐幇と嵩山派との交友
- 晁和の入門後、男弟子房でランダムに喧嘩の仲裁イベントが発生し、終了後に交友の可能性が開ける（ずっと寝て過ごした場合は対象外）。
- 仲裁イベント後に下山すると交友イベントが発生し、1回目は李富貴と樊嘯天、2回目は福韞と知り合う。
- 福韞との出会いイベントで福韞を殴る展開になり、その後お金が足りず秘笈を力ずくで奪おうとして共食い戦闘に敗北すると、生死簿87「共食い失敗」に到達する。
- 福韞との出会いイベントでは、助けるか傍観するかのいずれを選んでも許大鯨が唐門に加入し、集団戦の助けになる。
- 3人と交友しなくても進行自体は問題ないが、初心者にとっては交友しておいたほうが武林伝説エンディングに到達しやすく、その後のシナリオもより楽しめる。

### その他
- 葉氏兄妹が入居しており、かつ唐芳が帰還済みの場合、下山して遊ぶイベントが発生する。メインストーリーとはあまり関係ないが、上官螢の隠しイースターエッグが含まれており、上官螢の入居が条件となるため発生難易度は極めて高い。

## 下旬
- 第3回段階試験 (段考)。ここまで連勝してきた場合は女弟子と戦うことになる。一見すると負けたほうが良さそうに見えるが、勝っておかないと後で鬱憤を晴らす展開にならない。メインストーリーとは無関係なので好きに選んでよい。
