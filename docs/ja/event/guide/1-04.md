# {{ $frontmatter.title }}

## 上旬
### 1. ゲーム開始
- 世界観の簡単な紹介。ここでのイベントは後続の内容に影響しない。
- 最初の夜に鏡を見たとき「まあ悪くない (還不算差)」を選ぶと、趙活の立ち絵が少し整ったものになり、技能「自己陶酔 (自戀)」を獲得する。

### 2. 施設の初利用とチュートリアル
- 5月が終わるまでに女弟子房、煉丹房、厨房、練武場、男弟子房、講経堂へ初めて入ると、能力値が変化するイベントが発生するため有効活用したい。
- 初めて厨房に入ったとき【≧95】死ぬほど驚くを引くと、生死簿7「屁力焦蛙」を達成する。
- 心相が憂鬱の状態で男弟子房に入り、「琴棋書画」が発生して「あ、なんだか分かった気がする」を選ぶと、道具「大師兄の落書き」を獲得する。その後、[郁竹](/ja/people/characters/girl6)関連のイベントで「逆鱗宝衣」を入手できる (この情報は要検証)。
- 裏山での薪割りでは一定の確率で突き落とされるイベントが発生するが、後続の変化はまだ確認されていない。
- 5月が終わるまでに大門の市場でランダムに「荷物切り」を引くと、後続で[「怠け者」](/ja/event/simple/1-04-1-偷懶怪)関連のイベントが発生する。詳細はリンク先を参照。

## 中旬
- メインストーリーが自動で発生する。イベントの最後に手に入る秘笈は終盤になればすべて購入できるものの、序盤の戦力には非常に大きな影響を与える。
- 《五毒秘録》は医術5を達成する難易度を下げられるが、必須ではないため状況に応じて取得を検討するとよい。

## 下旬
- 四師兄の好感度が15以上あると[葉雲舟](/ja/people/characters/special3)・[葉雲裳](/ja/people/characters/girl2)兄妹に関連するイベントが発生する。このイベントとその後の展開では多額の銀両を得られるほか、葉雲裳との結縁ルートも開けるため発生させておくのがおすすめ。
- 葉氏兄妹のイベントは選択肢によって展開が変わり、初心者には戦闘の難易度が高すぎる場合があるため、事前にセーブしておくのが望ましい。
