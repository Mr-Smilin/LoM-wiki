# {{ $frontmatter.title }}

## 上旬
### 葉氏の行方をめぐる騒動
- 前提として、三師兄の好感度が2.5星以上、または江湖快報を3部所持していると、三師兄が宝について語るイベントが発生する。発生後に大門をクリックして外出すると続きが起きるが、事前に葉氏兄妹と知り合っていない場合は即座に中断され、その後の関連イベントや結縁は発生しなくなる。
- 葉雲舟の好感度が0未満かつ名声が10未満の場合もイベントが強制終了するため注意が必要。
- 点蒼派の門人との戦闘に敗北すると、生死簿51「点蒼の剣下に散る」に到達する。
- 最後の唐門での大戦に敗北すると、葉雲舟が唐門を信頼できなくなり、その後の関連イベントや結縁が断たれる。
- このイベントの後、葉雲裳に関連する大量のイベントが自動で解放される。

### 唐門の借金返済
- 最速で1年目8月上旬、遅くとも2年目4月下旬までに、唐門の借金が9000を下回ると発生する。
- 現時点では大きな役割はないものの、[上官螢](/ja/people/characters/girl4)に関わるため結縁に関係する可能性があるが、現バージョンでは上官螢との結縁はまだ実装されていない。
- 「香を焚く」を選び、すでに彼岸仙香を開発済みの場合、続いて脅迫を行って戦闘に敗北すると生死簿49「上官螢の制裁」に到達する。

## 中旬
- 晁和が初登場する。回避すること自体は可能だが、避けると実力の伸びが大きく制限されるためおすすめしない。
- この時点では晁和を倒し切ることはできず、無理に討とうとすると必ず死亡する。このイベント戦闘に敗北すると生死簿61「海賊版に生きる道を断たれて」に到達する。
- 晁和の登場後は関連イベントが大量に発生するが、基本的には能力値の増減のみ。詳細は[「晁和の悪だくみイベント集」](/ja/event/simple/1-08-3-晁和搞鬼事件集)を参照。

## 下旬
- 重要なイベントはなし。
