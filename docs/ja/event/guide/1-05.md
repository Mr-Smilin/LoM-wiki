# {{ $frontmatter.title }}

## 上旬
- 門派の貢献度制度が導入される。低い貢献度でもメインストーリーには影響しないが、貢献度が高いほうが能力値の変化が有利になりやすく、後の施設開放にも関わるため、普段から80以上を維持しておくのがおすすめ。
- 四師兄が自動で弾珠台を持ち込む。弾珠台の景品には優秀なものも含まれるため、詳細は[弾珠台](/ja/system/pinball#四師兄兜售)を参照。

## 中旬
- 重要なイベントはなし。

## 下旬
- 段階試験 (段考) イベントが始まる。全4回あり、第1回は難易度が非常に低く通常は問題なく突破できる。回を重ねるごとに難易度は上がるが、メインストーリーには影響せず、能力値への良好なボーナスが得られる。
- 第1回で敗北すると強制的にゲームオーバーとなり、生死簿10「小師妹の制裁」を獲得する。第2回以降に敗北した場合は、次回の段階試験で同じ相手と再戦になる。
