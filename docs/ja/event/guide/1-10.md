# {{ $frontmatter.title }}

## 上旬
- 南宮寿宴の話し合いが自動で発生する。これが最初の複数月にまたがる大型メインストーリーとなる。
- 「（小師妹が何か言いたそうにしている？）」を選ぶと小師妹も寿宴に参加するが、メインストーリーへの影響は大きくない。
- 「霊丹を献上する」を引くと1ターン強制的に煉丹房しか選べなくなるが、屍心丹に関連するシナリオを見られる。
- 「耕陽読書斎の墨宝」を引くと、江湖快報の所持数に応じて貢献度が上昇する。
- 「仇敵を始末する」を引くと早めに出発することになる。このルートは難易度が高いため初心者には向かない。

## 中旬
- 寿宴の話し合いで「仇敵を始末する」を引いた場合、この時点で強制出発となる。能力値の変化を有利にするため、上旬のうちにお金を使い切り、心相を80以上まで上げておくのがおすすめ。

## 下旬
- 特別なシナリオはない。先行して寿宴へ出発した場合はこの期間がスキップされる。
