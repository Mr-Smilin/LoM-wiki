## 条件と手順

<b>条件：</b>崆峒派に留学<br>
<b>手順：</b><br>

1. 2年目2月初旬の行動前－唐門会議で、**📜 議題：(イベント)崆峒派へ留学したい**を選択。
2. 2年目5月下旬の行動前－崆峒季試：
    1. **📖 選択肢：挑戦する**
    2. 第1試合。**🎲 天命：勝負……**(上限99)：
        - **🧾【＜50】南宮浅の勝利**：**🆚 決闘：南宮浅**で勝利が必要。
        - **🧾【≧50】南宮浅の敗北**：**🆚 決闘：青城弟子**で勝利が必要。
    3. 第2試合。**🎲 天命：あなたの次の相手は……**(上限99)：
        - **🧾【＜25】火を噴く法術を会得した剣客**：**🆚 決闘：点蒼弟子**で勝利が必要。
        - **🧾【＜50】闇討ちの技を覚えた僧侶**：**🆚 決闘：嵩山弟子**で勝利が必要。
        - **🧾【＜75】逸品の武器で武装した女侠**：**🆚 決闘：錦香宮弟子**で勝利が必要。
        - **🧾【≧75】心身の修養を積んだ闘士**：**🆚 決闘：峨嵋弟子**で勝利が必要。
    4. 第3試合。**🎲 天命：あなたの次の相手は……**(上限99)：**🧾【＜33】丐幇の狂犬**：**🆚 決闘：樊嘯天（ハンショウテン）**で敗北が必要。
    5. **🎲 天命：樊嘯天の理性……**(上限99、＋加値：樊嘯天好感度)：**🧾【＜70】無視**。殺される。
