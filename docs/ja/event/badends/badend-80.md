## 条件と流程

<b>条件：</b>[南宮浅](/ja/people/characters/special103)好感度 ≧40<br>
<b>流程：</b><br>

1. 第3年10月中旬[武林大会](/ja/event/simple/3-10-2-武林大會)で[南宮遠](/ja/people/characters/special101)が死亡する。
2. [戦後の雑談](/ja/event/simple/3-10-2-戰後閒聊)にて、**📜 議題：(雑談)負傷者**→**📜 議題：(雑談)南宮世家に弔意を伝える**。
3. [南宮浅](/ja/people/characters/special103)好感度 ≧40で選択が発生：**📖 選択：南宮浅を追う**。
4. [南宮浅を追う](/ja/event/simple/3-10-2-追南宮淺)後の📖 選択は3つあるが影響しない。**🆚 決闘：[南宮浅](/ja/people/characters/special103)**に敗北した後、[袁無憲](/ja/people/characters/special823)に借刀で殺される。
