## 条件と手順

<b>条件：</b>崆峒派に留学、虞小梅が唐門に加入、想い人が郁竹でない・郁竹好感度＜45・郁竹が唐門にいない、のいずれか<br>
<b>手順：</b><br>
1. 第2年2月上旬唐門会議で**📜「崆峒派へ留学したい」**を選ぶ。
2. 第2年10月下旬、虞小梅が唐門に加入(虞小梅好感度≧20が必要)。
3. 第3年1月の[唐布衣](/ja/people/characters/brother1)の下山イベントで、虞小梅に孤島へ連れて行かれる (条件は[飛侠の帰還](/ja/event/detailed_description/4-02-2-飛俠歸來)を参照)。
4. 想い人が郁竹でない・郁竹好感度＜45・郁竹が唐門にいない、のいずれかでエンディングに進む。
