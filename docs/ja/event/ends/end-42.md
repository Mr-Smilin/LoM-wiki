# {{ $frontmatter.title }}

<EndBackground no=42 title="隠世の大儒">
あなたたち夫婦には気骨があり、驕りはなかった。<br>
文人墨客も、物売りも人足も、誰であれ歓迎した。<br>
談笑に鴻儒あり、往来に白丁を拒まず。<br>
士農工商みな友となり、<br>
真剣に生きるすべての人を、等しく敬った。<br>
