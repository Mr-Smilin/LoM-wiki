## 条件とフロー

<strong>条件：</strong>[李富貴](/ja/people/characters/special809)の好感度＜20 または丐幇の好感度＜2、かつ「金烏上人が存命 ([金烏上人の死](/ja/people/characters/special207_death))」「スキル：戦術＜5」「スキル：戦術＜8かつ学問＜60」のいずれか<br>

     + **📜議題「決定：江湖から隠居」**：江湖から隠居＋１票。
   + **🎲運命：三師兄の決断......**(上限70、➕加値：名声)：
     + 獲得**🧾【＜60】門弟を解散**：江湖から隠居＋１票。
     + 獲得**🧾【≧60】敵と戦う**：江湖から隠居＋１票。
   + **🎲運命：四師兄の決断......**(上限99、➕加値：名声)：
     + 獲得**🧾【＜80】門弟を解散**：江湖から隠居＋１票。
     + 獲得**🧾【≧80】敵と戦う**：江湖から隠居＋１票。
   + **🎲運命：小師妹の決断......**(上限99、➕加値：<Girl0Icon>唐黙鈴</Girl0Icon>好感度*0.1)：

4. 以下の条件を満たして、門弟を解散することを決定：
   + 江湖から隠居の票が多い。
   + 票が同数で主人公が江湖から隠居を選択し、🗡️[唐陞](/ja/people/characters/brother3)との決闘に勝利。
   + 票が同数で[唐陞](/ja/people/characters/brother3)が江湖から隠居を選択し、🗡️[唐陞](/ja/people/characters/brother3)との決闘に敗戦。

## 分岐と変化

### 行き先
大門を出る前に行き先の選択があり、伝説テキストに加わる。一部の地点のコンテンツは結婚対象、想い人、唐門に加入した成員によって異なる。

### 結婚対象
結婚対象が異なると、エンディングストーリーが異なるが、伝説テキストに影響しない。<br>
※門人解散エンディング結婚優先順位(v1.0.3200.2)：<Girl0Icon>唐黙鈴</Girl0Icon>＞<Girl2Icon>葉雲裳</Girl2Icon>＞<Girl4Icon>上官螢</Girl4Icon>＞<Girl3Icon>虞小梅</Girl3Icon>＞<Girl6Icon>郁竹</Girl6Icon>＞<Girl7Icon>魏菊</Girl7Icon>＞<Girl5Icon>夏侯蘭</Girl5Icon>

### 唐惟元が帰還
[唐惟元](/ja/people/characters/brother4)が以前帰還していた場合、エンディング前のプロット内に登場するが、伝説テキストに影響しない。

### 唐門に加入した成員
以下の成員が唐門に加入した場合、エンディング前のプロット内に登場し、伝説テキストに影響しない。
+ [福韞](/ja/people/characters/special206)：武林大会に向かう途中に[覚醒](/ja/people/characters/monk2)が嵩山へ行くことを約束したかどうかによって、異なるセリフがある。
+ [樊嘯天](/ja/people/characters/special4)：[樊嘯天](/ja/people/characters/special4)が<Girl5Icon>夏侯蘭</Girl5Icon>に師事しているかどうかによって、異なるセリフがある。
