# {{ $frontmatter.title }}

<EndBackground no=55 title="活きる">
あなたは余生ずっと負い目を抱え、あの頃を思い出すたび、<br>
恥ずかしさに居たたまれなくなる。<br>
小竹はそれを見ると、黙ってあなたに寄り添い、あなたが落ち着くまでそばにいる。<br>
あなたが彼女に寄り添われると動けなくなるのは、半分は温もりのため、<br>
半分は泰山に押さえつけられるような重みのためだ。<br>
</EndBackground>
