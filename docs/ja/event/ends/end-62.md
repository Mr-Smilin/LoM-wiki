# {{ $frontmatter.title }}

<EndBackground no=62 title="新しい家">
唐門のいわゆる外姓の者は、来歴を問わず、出自を詮索しない。<br>
塀の内に迎え入れ、漁と耕しの恵みを分け与え、身を落ち着けさせ、去るも留まるも咎めない。<br>
羽が十分に育った日が、翼を広げて飛び立つ時である。<br>
