# {{ $frontmatter.title }}

<EndBackground no=41 title="千古の名匠">
あなたと小竹は精妙比類なきからくり人形を造り上げ、<br>
池の底に隠した。<br>
構造があまりに複雑なため大きく造らざるを得ず、<br>
人・獅子・鷹の三体に分かれ、合体もできる。<br>
青史に名を刻むに足る偉業だが、二人は悪用を恐れ、<br>
最後には壊すことを選んだ。<br>
</EndBackground>
