# {{ $frontmatter.title }}

<EndBackground no=30 title="山林の隠者">
二人は隠棲の雅士。どうせこの時代の方が、<br>
二人には釣り合わないのだ。孤高を楽しみ、<br>
我が身を善くすればいい。晴れの日は耕し、<br>
雨の日は書を読み、夏は蓮を愛で、冬は雪を眺める。<br>
それもまた、心楽しいではないか。<br>
