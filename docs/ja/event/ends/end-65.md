# {{ $frontmatter.title }}

<EndBackground no=65 title="崆峒掌派人">
唐門の灯が消えたその日から、あなたは鋭気をしまい込み、<br>
身は江湖にあっても、心はそこになかった。<br>
あなたの治世のもと、崆峒派は次第に武林の争いから遠ざかり、<br>
道に不正を見ても保身に徹した。<br>
もう余計な世話は焼かない。<br>
武を尚ぶが、俠ではない――武俠は崆峒にない。<br>
</EndBackground>
