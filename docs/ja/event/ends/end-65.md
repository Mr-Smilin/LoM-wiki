# {{ $frontmatter.title }}

<EndBackground no=65 title="崆峒掌派人">
唐門の灯が消えたその日から、あなたは鋭気をしまい込み、<br>
身は江湖にあっても、心はそこになかった。<br>
あなたの治世のもと、崆峒派は次第に武林の争いから遠ざかり、<br>
道に不正を見ても保身に徹した。<br>
もう余計な世話は焼かない。<br>
武を尚ぶが、俠ではない――武俠は崆峒にない。<br>
</EndBackground>

## 条件と流れ
1. 3年目12月上旬、[「武林盟への対策」](/ja/event/simple/3-12-1-武林盟對策#退隱江湖)で江湖からの引退を決め、[「唐門との別れ」](/ja/event/simple/3-12-1-告別唐門)に進む。
2. 次のどちらかに当てはまる:
   + <Girl3Icon>虞小梅</Girl3Icon>と結縁していて、[厨房](/ja/event/simple/3-12-1-告別唐門#伙房)で**📖「崆峒へ行く」**を選び、続けて小梅が金国につこうと持ちかけたときに**📖「駄目だ」**を選ぶ。
   + <Girl6Icon>郁竹</Girl6Icon>と結縁していて、[鍛冶場](/ja/event/simple/3-12-1-告別唐門#鍛冶場)で**📖「崆峒へ行く」**を選ぶ。
3. [大門](/ja/event/simple/3-12-1-告別唐門#大門)を選ぶと、エンディングに進む。
