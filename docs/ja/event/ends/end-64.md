## 条件と流れ
1. <Girl3Icon>虞小梅</Girl3Icon>と結縁する ([虞小梅結縁攻略](/ja/event/pursuit/girl3)を参照)。
2. 3年目12月上旬、[「武林盟への対策」](/ja/event/simple/3-12-1-武林盟對策#退隱江湖)で江湖からの引退を決め、[「唐門との別れ」](/ja/event/simple/3-12-1-告別唐門)に進む。
3. [厨房](/ja/event/simple/3-12-1-告別唐門#伙房)で小梅に崆峒へ行くかと聞かれたら、**📖「崆峒へ行く」**を選ぶ。続けて小梅が崆峒を率いて金国につこうと持ちかけたら、**📖「いいぞ」**を選ぶ (道徳-3)。
4. [大門](/ja/event/simple/3-12-1-告別唐門#大門)を選ぶと、エンディングに進む。

## 備考

- エンディングでは後世の人があなたの銅像を鋳造し、通りがかる人が毎日その像に平手打ちをする。岳王廟の前にある秦檜の跪像と同じ扱い。
