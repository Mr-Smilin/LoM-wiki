## 条件とフロー

<strong>条件：</strong><Girl8Icon>龍湘</Girl8Icon>以外の者と婚約、<Girl8Icon>龍湘</Girl8Icon>が唐門に加入、想い人が<Girl8Icon>龍湘</Girl8Icon>、門人解散<br>
**フロー：**<br>

1. 第三年十月中旬の武林大会で、<Girl8Icon>龍湘</Girl8Icon>好感≧30。[錦香宮の真相](/ja/event/simple/3-10-2-錦香真相#龍湘求助)で錦香宮が暴露された後、龍湘が助けを求めてきた時に**📖「周囲の冷眼に構わず龍湘を受け入れる」**を選択すると、<Girl8Icon>龍湘</Girl8Icon>が唐門に加入。
2. 第三年十二月上旬の最後の行動前に、西武林盟を成立させられない (条件は[衆人の決断](/ja/event/detailed_description/3-12-1-眾人的決策)を参照) 場合、[武林盟への対策](/ja/event/simple/3-12-1-武林盟對策)イベントに進む。
3. 敵と隠居について投票を実施：[唐惟元](/ja/people/characters/brother4)が帰還した場合、[唐惟元](/ja/people/characters/brother4)の投票が追加される。唐黙鈴と婚約した場合、<Girl0Icon>唐黙鈴</Girl0Icon>の投票が追加される。
   + 主人公の決断：
     + **📜議題「決定：ぶちのめしてやる」**：決戦＋１票。
     + **📜議題「決定：江湖を去り隠遁する」**：江湖から引退＋１票。
   + **🎲運命：三師兄の決断......**(上限70、➕加値：名声)：
     + **🧾【＜60】門弟の解散**：江湖から引退＋１票。
     + **🧾【≧60】ぶちのめしてやる**：決戦＋１票。
   + **🎲運命：四師兄の決断......**(上限99、➕加値：名声)：
     + **🧾【＜80】門弟の解散**：江湖から引退＋１票。
     + **🧾【≧80】ぶちのめしてやる**：決戦＋１票。
   + **🎲運命：小師妹の決断......**(上限99、➕加値：<Girl0Icon>唐黙鈴</Girl0Icon>好感度*0.1)：
     + **🧾【＜30】紙が折り鶴になっている**：無効票。
     + **🧾【＜70】江湖を去り隠遁する**：江湖から引退＋１票。
     + **🧾【≧70】師兄と同じ**：主人公の票数＋１。
4. 以下の条件を満たして、門弟を解散することを決定：
   + 江湖から引退の票が多い。
   + 票が同数で主人公が江湖から引退を選択し、🗡️[唐陞](/ja/people/characters/brother3)との決闘に勝利。
   + 票が同数で[唐陞](/ja/people/characters/brother3)が江湖から引退を選択し、🗡️[唐陞](/ja/people/characters/brother3)との決闘に敗戦。
5. [唐門との別れ](/ja/event/simple/3-12-1-告別唐門)の際に後山へ向かい、**📖選択肢「湘姉、一緒に来ませんか？（心を明かす）」**(選択肢を開くには想い人が<Girl8Icon>龍湘</Girl8Icon>である必要があります)。
6. 既に他のキャラと婚約している場合、🗡️<Girl8Icon>龍湘</Girl8Icon>が決闘を仕掛け、勝利後に**📖選択肢「君を手放すことはない」**を選択、エンディングに進む。
