1. 第二年二月上旬唐門会議で、**📜議題：(イベント)崆峒派へ留学したい**を選択。
2. 第二年三月上旬、門派くじに参加が必要。奪魄門に加入する際に<Girl5Icon>夏侯蘭</Girl5Icon>と出会える。
    - 第二の判断で**📖判断：師門の名声のため賛同する。**を選択。

4. 第二年四月上旬の行動前に、奇襲を受ける：
    1. **🎲天命：結果は......**(上限90、➕加値：拳掌)：**🧾【＞50】防御成功**。
