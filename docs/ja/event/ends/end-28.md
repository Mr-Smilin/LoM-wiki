# {{ $frontmatter.title }}

<EndBackground no=28 title="血河刀">
利に目の眩んだ江湖の者たちは、<br>
誰一人あなたの企みを見抜けなかった。<br>
あなたはこの刀で唐門の仇を討った。一人も斬らぬまま、<br>
刀の下には千万の屍が伏し、血は河を成した。<br>

## 条件と流れ
1. <Girl6Icon>郁竹</Girl6Icon>と結縁する ([郁竹結縁攻略](/ja/event/pursuit/girl6)を参照)。
2. 3年目12月上旬、[「武林盟への対策」](/ja/event/simple/3-12-1-武林盟對策#退隱江湖)で江湖からの引退を決め、[「唐門との別れ」](/ja/event/simple/3-12-1-告別唐門)に進む。
3. [鍛冶場](/ja/event/simple/3-12-1-告別唐門#鍛冶場)で郁竹が引退の話をしたら、**📖「いや、江湖にはもう面白みを感じない。」**を選ぶ (鍛冶場に行かなくても同じ)。
4. [大門](/ja/event/simple/3-12-1-告別唐門#大門)を選び、道徳≦40 ならエンディングに進む。

## 備考

- 『倚天屠龍記』に「武林至尊、宝刀屠龍、号令天下、莫敢不従。倚天不出、誰与争鋒」という一節がある。「屠龍」は屠龍刀、「倚天」は倚天剣のこと。江湖の者が一振りの刀を奪い合って血を流すこの結末は、屠龍刀をめぐる争いと重なる。
