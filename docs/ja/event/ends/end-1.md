# {{ $frontmatter.title }}

<EndBackground no=1 title="回疆隠棲">
二師兄の追撃を恐れたあなたは唐門を逃れ、<br>
遠く回疆へ難を避けた。<br>
苗の逞しい女に婚姻を迫られ、<br>
婚後は子と孫に恵まれた。<br>
だが心はついぞ晴れず、四十を待たずして、<br>
病もなく世を去った。<br>
</EndBackground>
