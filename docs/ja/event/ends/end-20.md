## フロー

青城留学中の行動で功績ポイントを貯める。ポイントの内訳は次のとおり：
+ 上清宮：修真 +1
+ 上清宮道士 +1<br>
(地獄道と誤認時+0、鬼卒助陣で五ターン対戦+1)
+ 青城山町医館－青城弟子の診察 +2
+ 常風観散歩－吟じながらそぞろ歩き、悟るところあり、通りすがりの侠客に負ける -1

二年目九月下旬に鄒博が戻った後で上清宮を訪れる。功績ポイント≥6なら[鄒博の激励](/ja/event/simple/2-09-3-鄒博嘉勉)イベントが発生するので、「よし、青城に入門して道を学ぶ」を選ぶ。
