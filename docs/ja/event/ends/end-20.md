## フロー

青城留学期間中、活動を実施して功績ポイントを累積します。計点は以下の通り：
+ 上清宮修真 +1
+ 上清宮道士 +1<br>
(地獄道と誤認時+0、鬼卒助陣で五ターン対戦+1)
+ 青城山鎮医館－青城弟子求診 +2
+ 常風観散歩－吟じながらそぞろ歩き、悟るところあり、通りすがりの侠客に負ける -1

二年目九月下旬に鄒博が帰来した後、上清宮を訪問。功績ポイント≥6の場合、[鄒博の激励](/ja/event/simple/2-09-3-鄒博嘉勉)イベントが発動し、【青城派に入門】を選択。
