# {{ $frontmatter.title }}

<EndBackground no=39 title="地方一の富豪">
上官螢のおかげで、趙家は地方一の豪家となった。<br>
上官螢は次第に商売をあなたに任せ、<br>
自らは家政を執った。<br>
賢妻良母たる彼女は、決して子供を打たなかった。<br>
子供が過ちを犯した時は、あなたを打った。<br>
