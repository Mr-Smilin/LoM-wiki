<EndBackground no=59 title="自創の武功">
あなたは自らの境遇に納得できず、世の人々への復讐として一冊の秘笈を伝えた。<br>
冒頭にはこう書かれている。「神功を練らんと欲せば、刀を揮い自ら宮せよ」。<br>
数え切れない英雄が子孫を絶やすこととなった。<br>
