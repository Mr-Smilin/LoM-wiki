# {{ $frontmatter.title }}

[極楽教](/ja/people/factions/elysium-school)滅亡後、極楽左使野利察漢は逃げおおせ、数年後に再び現れた。彼は姿を変えて宋人になりすまし、自ら「[李元棄](/ja/people/characters/special213)」と名乗った。民の怨みを煽って郴州で兵を挙げた。世に「白風峒変乱」と呼ばれる事件で、ここ十年で江湖最大の出来事と言えるだろう。
<br><br>
朝廷は江湖の争いを昔から放任しており、民衆の安危に関わるか、官家の威信を揺るがすのでない限り手を出さなかった。旧魔教と正派の争いについて、朝廷は手を出さなかったのである。この度、一般民衆が巻き込まれたため、朝廷もついに傍観できず、兵を派遣して乱賊を討伐し、湘・贛の地で激戦を繰り広げることになった。
<br><br>
李元棄は戦略に長け、何度も降参を装って官兵を手玉に取り、また大宋の民衆を盾にして、一時は一万人以上の兵力を有し、勢いは盛んだった。官兵は久しく攻撃しても落とせず、江湖の勢力も勝手に出動できない状況が続き、戦況は膠着した。江南西路軍、湖南路軍、池州、江州の正副都統が率いる軍が相次いで白風軍に敗れ、李軍の士気はますます高まり、彼を明教教主方臘に比する者さえ出てきた。
<br><br>
膠着を打ち破ったのは五人の江湖侠士である。唐門の[飛侠](/ja/people/characters/brother1)、峨嵋の[風神](/ja/people/characters/special808)、崆峒の[奪魄幽蘭](/ja/people/characters/girl5)、そして残りの二人は脱走兵と捕快だったとされている。五人は[丹霞子](/ja/people/characters/special404)道法将軍と謀って官兵を囮にし、敵の本陣へ一気に攻め込んで乱戦の中で極楽左使を討ち取った。こうして中原の大きな災いは免れたのである。
<br><br>
朝廷の介入があったため、白風峒変乱は極楽教ほど深刻な禍いにはならなかったが、侮ってはいけない。李元棄が民衆を扇動して反乱を起こし、朝廷に正面から対抗したという事実だけでも、史冊に記されるに値する。

## 備考

- 白風峒変乱は史実では「黒風峒変乱」（1208-1211年）を指し、李元棄は史実人物「李元礪」に対応している。[ウィキペディアリンク](https://zh.wikipedia.org/zh-tw/%E9%BB%91%E9%A3%8E%E5%B3%92%E5%8F%98%E4%B9%B1)
- 白風軍の討伐に当たったのは廂兵にすぎず、大宋の真の精鋭は襄陽で金兵に釘付けにされていた。もし李元棄が好機を捉えて九江を占領し、水路の要衝を押さえて険阻に拠り、力を蓄えつつ江南西路から婺州・越州へ進軍していたなら、あるいは臨安へ矛先を向け、朝廷にとって心腹の大患となっていたかもしれない。
- 白風峒変乱の時代、葉家は言論によって罪に問われ、当時の皇帝の不興を買って一族皆殺しの惨禍に遭った。葉家の兄妹はこうして孤児となったのである。
