## 存活の鍵

第3年1月中旬、**🎲天命：幾人の援手が必要か？....**(上限60、➕加値：[唐布衣](/ja/people/characters/brother1)好感度）：
   + **🧾【＜80】必要ない**：[唐布衣](/ja/people/characters/brother1)と一緒に下山しない。
   + **🧾【≧80】必要ない、俺と趙活だけで十分だ。**、その後以下を選ぶ：
      + **📖選択：行くもんか（激しく抵抗）**：[唐布衣](/ja/people/characters/brother1)と一緒に下山しない。ただし想い人が<Girl0Icon>小師妹</Girl0Icon>のときは小師妹に説き伏せられ、結局[唐布衣](/ja/people/characters/brother1)と一緒に下山する。
      + **📖選択：全くしょうがねぇな！**：[唐布衣](/ja/people/characters/brother1)と一緒に下山する。

### 唐門に待機

第3年1月下旬、[唐布衣](/ja/people/characters/brother1)が重傷を負って運び込まれる。
1. 趙活が[唐布衣](/ja/people/characters/brother1)の治療を思い立つ経路は次の2つで、どちらか一方を満たせばよい。どちらも満たさないと趙活には手の施しようがなく、[唐布衣](/ja/people/characters/brother1)はその夜に息を引き取る。
   + 経路一: 医術スキル≧5、または[隠しパラメータ一覧](/ja/system/hidden-params#全煉丹點數)の累計煉丹点数≧250。
   + 経路二: 泥教各道の好感度の合計＞1 (下の「泥教各道の好感度を得る方法」を参照)。<br>山麓で泥教弟子に出会ったとき、彼らを唐門へ匿う選択肢を選ぶ。<br>その後、泥教弟子が煉丹房で、大師兄の内傷の原因と、同門の者の気で治療できることを教えてくれる。
2. **📖選択：躊躇する** は結果に影響しない。ただし、躊躇したあとの最初の2回は📖「自分のことを考えて何が悪い？」を選んではいけない。
3. 治療を始めると内力が減る。治療前の内力と、[南宮心法](/ja/system/books/book_7012)の南宮護心訣の等級から、大師兄の生存点が次のように決まる:
   + 南宮護心訣の等級＜3、かつ治療前の内力≧55: 生存点 = 2。
   + 南宮護心訣の等級＜3、かつ治療前の内力＜55: 生存点 = 1。
   + 南宮護心訣の等級 = 3、かつ治療前の内力≧53: 生存点 = 3。
   + 南宮護心訣の等級 = 3、かつ53＞治療前の内力≧28: 生存点 = 2。
   + 南宮護心訣の等級 = 3、かつ治療前の内力＜28: 生存点 = 1。
4. 続いて、治療を途中で📖「やめる」か📖「やめない」かで、生存点が次のように引かれる:
   + 小梅が唐門にいる ([小梅、唐門を頼る](/ja/event/simple/2-10-3-小梅投靠)参照) かつ「やめる」: 孤島の結末に入る。飛侠の帰還は解放できない。
   + 小梅が唐門にいる かつ「やめない」:
      + <Girl6Icon>郁竹</Girl6Icon>が唐門にいる ([南宮家からの訃報](/ja/event/simple/2-10-1-南宮訃音)参照)、または<Girl3Icon>虞小梅</Girl3Icon>好感度≧40: 生存点は引かれない。小梅が敵を追い払うのを手伝い、趙活は金烏上人の死んだふりを見られない。
      + <Girl6Icon>郁竹</Girl6Icon>が唐門にいない、かつ<Girl3Icon>虞小梅</Girl3Icon>好感度＜40: 小梅が趙活を連れ去り、「やめる」と同じく孤島の結末に入る。飛侠の帰還は解放できない。
   + 小梅が唐門にいない かつ「やめる」: 生存点-1。続けて何度か戦闘になり、趙活は金烏上人の死んだふりを見られる。
   + 小梅が唐門にいない かつ「やめない」: 生存点は引かれない。戦闘はなく、趙活は金烏上人の死んだふりを見られない。
5. 最後に、生存点≧2 なら大師兄は生き残る。

::: details 泥教各道の好感度を得る方法
1. 第1年12月の[南宮寿宴](/ja/event/simple/1-12-1-南宮壽宴)で、南宮の仇人ルートなら地獄道の好感度+1。
2. 第2年9月の[南宮家での夜間行動](/ja/event/simple/2-09-1-南宮家夜遊)で「追いかけて様子を見る」を選び、気絶させられなかった場合、第2年10月の虞小梅の襄陽行で「買い出し」をするときに、戦術スキル≧3、性情≧60、道徳≧60 なら天道の好感度+1。
3. 第2年11月、青城留学ルートの[趙逵の登山](/ja/event/simple/2-11-3-趙逵上山)で道徳＞40 のとき、展開しだいで地獄道の好感度+2 まで得られる。
4. 青城留学中、青城山鎮の「診療」で「鬼卒の治療」が起きたとき (地獄道の好感度≧1 で起きる)、「約束だ」を選ぶと地獄道の好感度+1。
:::

::: details 虞小梅が唐門に加入する条件

2. 第2年10月下旬、<Girl3Icon>虞小梅</Girl3Icon>好感度≧20。

### 一緒に下山

1. 第3年1月中旬、唐門に戻る途中で[金烏上人](/ja/people/characters/special207)に奇襲される。**🎲天命：君の対手**(上限99、➕加値：<Girl3Icon>虞小梅</Girl3Icon>好感度)：
   + **🧾【＜80】金烏上人**：[金烏上人](/ja/people/characters/special207)と決闘する。負けるか、勝っても奇襲をかわせなかった場合は、金烏上人に頭を叩かれる。かわせた場合は[申屠龍](/ja/people/characters/special405)に内力を吸われる。
   + **🧾【≧80】金烏上人の横にいる悪い女**：
      + 小梅が唐門にいない ([小梅、唐門を頼る](/ja/event/simple/2-10-3-小梅投靠)参照)：女盗賊と決闘する。勝てば申屠龍に内力を吸われる。負けると<BadendIcon :no="37">生死簿 No.37「女盗賊の待ち伏せ」</BadendIcon>。
      + 小梅が唐門にいる：<Girl3Icon>虞小梅</Girl3Icon>と決闘する。下の[小梅ルート](#小梅ルート)を参照。
2. [金烏上人](/ja/people/characters/special207)に頭を叩かれず、[申屠龍](/ja/people/characters/special405)に内力を吸われる場合、以下の条件のいずれかを満たすと唐布衣は生き残る：
   + 名声≧50かつ道徳≧80【侠客】。
   + [申屠龍](/ja/people/characters/special405)を知っており好感≥30。
3. 頭を叩かれたか上記の条件を満たさない場合でも、運命≧30(下山で消費するのが最も簡単な達成方法)なら、帰り道で気を失っている間に[瑞杏](/ja/people/characters/girl1)の夢を見る。運命が足りないと、この夢は出ない：
   + **📖選択：どうしても大師兄には生きていてほしい**：運命-30、大師兄は生き残る。
   + **📖選択：はい。**：心相+30、運命+1、大師兄は生き残らない。

#### 小梅ルート

1. <Girl3Icon>虞小梅</Girl3Icon>との決闘に勝つと、申屠龍に内力を吸われる。上の 2. と同じ。
2. 負けるか、<Girl3Icon>虞小梅</Girl3Icon>好感≧50 のときに最初の 7 ラウンドを防御と口功だけで 8 ラウンド目まで持ちこたえる (小梅が手を止める) と、次の条件で分岐する：
   + <Girl6Icon>郁竹</Girl6Icon>が唐門にいる ([南宮家からの訃報](/ja/event/simple/2-10-1-南宮訃音)参照)：
      + <Girl3Icon>虞小梅</Girl3Icon>好感≧20：小梅が趙活を連れ去り、孤島の結末に入る。飛侠の帰還は解放できない。
      + <Girl3Icon>虞小梅</Girl3Icon>好感＜20：<BadendIcon :no="38">生死簿 No.38「小梅の刺殺」</BadendIcon>。
   + <Girl6Icon>郁竹</Girl6Icon>が唐門にいない：
      + <Girl3Icon>虞小梅</Girl3Icon>好感＜45：<BadendIcon :no="38">生死簿 No.38「小梅の刺殺」</BadendIcon>。
      + <Girl3Icon>虞小梅</Girl3Icon>好感≧45：小梅が寝返り、大師兄と手を組んで[金烏上人](/ja/people/characters/special207)を殺す。このルートで内力を吸われるのは大師兄と小梅なので、上の 2. の条件は数に入らない。大師兄を生かせるのは 3. の夢だけ。

## 帰還の時期

+ **前提**：イベント当初は唐布衣の生死が不明のままで、以下のいずれかのタイミングで帰還する
+ **西武林盟ストーリーライン**：第4年2月中旬、[東西武林盟会戦](/ja/event/detailed_description/4-02-2-東西武林盟會戰)、結縁対象がいなくても可。
+ **徹底抗戦ストーリーライン**：第4年1月または2月中旬、[唐門囲攻戦](/ja/event/detailed_description/4-01-2-唐門圍攻戰)、結縁対象がなく、[武林盟主](/ja/people/characters/special999)に勝利して<EndIcon no="46">汗青書46：漫才二人組</EndIcon>に進む。

どちらのルートでも、実績<AchievementIcon :size="`small`" :no="`17`">飛侠の帰還</AchievementIcon>を解放する。
