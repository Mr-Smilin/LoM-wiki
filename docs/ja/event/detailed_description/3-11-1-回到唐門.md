**発生時期**：第三年11月上旬 ([武林大会からの帰路](/ja/event/detailed_description/3-10-2-武林大會歸途)から連続)<br>

## 唐門に帰る (回到唐門)

「三師兄、ただいま」。武林大会の顛末を報告する。道中の茶店では号外が出回っており、
南宮家当主が人間道法王の手にかかり、[温夫人](/ja/people/characters/special402)のために
死んだことが伝わっている。

+ 武林大会で死傷者を出さなかった場合：貢献+20、[唐陞](/ja/people/characters/brother3)好感+3
+ 「家に帰ってきた」：心相+30
+ [樊嘯天](/ja/people/characters/special4)が唐門に加入している：会話が追加される
+ [夏侯蘭](/ja/people/characters/girl5)と結縁している：心相-10
  + さらに[樊嘯天](/ja/people/characters/special4)が入門していない場合：心相+50

## 弟子が暇乞いする (弟子想告辭)

行動回数が残り1回になると自動発生。下山しようとする弟子を引き留める場面。

+ **🎲弟子の意図**(上限50、➕加値：団結)
  + **🧾【＜75】「俺たち、出ていきます」** → **📖選択**
    + 👉「行かせるかよ」：**🆚戦：唐門弟子**
      + 勝利：道徳-2、武学+4、[唐陞](/ja/people/characters/brother3)好感-2
      + 敗北：[唐陞](/ja/people/characters/brother3)好感+、門人-2
    + 👉「適当な言葉で送り出す」：弁舌+、処世+、品性-、門人-2
    + 👉「礼を尽くして送り出す」：処世-、品性+、[唐陞](/ja/people/characters/brother3)好感+、門人-2
  + **🧾【≧75】「出ていくつもりでしたが、考え直しました」**：弟子は残留する

## 四師兄が帰る (四師兄歸來)

[四師兄、商いの長旅へ](/ja/event/detailed_description/3-08-1-四師兄遠遊經商)で
土産を頼んでいた場合のみ、[唐惟元](/ja/people/characters/brother4)がこの時期に帰還する
(頼まなかった場合は永久離脱のため帰還しない)。

+ [唐惟元](/ja/people/characters/brother4)好感-4
+ 頼んだ土産の内容によって会話が変わる
  + 「小師妹がどう過ごしているか知りたい」を選んでいた場合：[劉顎](/ja/people/characters/special1)好感≧20 で会話が変化する
  + 「華山には仙人がいて、仙人は霊丹を持つと聞いた」を選んでいた場合：
    [龍湘](/ja/people/characters/girl8)の悩みごとに関する会話が追加される。
    唐門が支持する対象によっても会話差分がある

## 備考

+ 四師兄が帰還していると、後の西武林ルートで彼を崆峒へ使者に立て、崆峒派の支持を得られる。
