## 基本の流れ

**カテゴリ**：メインシナリオ<br>
**発生時期**：第三年10月中旬 (武林大会の閉幕後。唐門への帰還は11月上旬)<br>
**発動条件**：メイン進行で自動発生<br>

1. **宿屋で休む**：飛石幇が餓鬼道・地獄道の迎撃に加勢していれば会話追加。門派投票の結果、
   [龍湘](/ja/people/characters/girl8)を受け入れているか（受け入れていれば「食欲もない」といった会話追加）でそれぞれ会話差分。
   [樊嘯天](/ja/people/characters/special4)が唐門に加入していれば拝師の会話差分
   （👉「犬は外で寝かせろ」：処世-1、樊嘯天好感-1。道徳≦40なら追加会話 ／
   👉「金があれば鬼も使える」(要銀両≧1000)：処世+1、性情+1、品性-2、銀両-1000、名声-1、樊嘯天好感+3。処世＜60なら会話差分）。
   死傷者数の結果でも会話差分。心相=0なら体力-1、性情-1、品性-1。[上官螢](/ja/people/characters/girl4)との約束があれば会話追加。休憩画面が開く (セーブ可)
   + 💬「水を一桶頼んで体を洗う」：品性+1、心相+20（銀両≧200なら銀両-200、銀両＜200なら貢献-10、門派資産-20）
   + **▲下で酒を飲む**：👉「余分にチップを」(要銀両≧100)：銀両-100、道徳+1、処世+1 ／「そのままで結構」：影響なし
   + **☯夜の客舎で[南渓](/ja/people/characters/special829)に遭遇**：
     [葉雲裳](/ja/people/characters/girl2)ルートで[葉雲舟](/ja/people/characters/special3)を
     唐門代表として試合に出している場合
     (趙活自身が上官隼への挑戦などで舞台に上がると、葉雲舟は唐門名義で出場できない)、
     宿で階下に降りたときに発生する。
     店じまいの宿に嶺南四醜が押しかけ、南渓が斬り捨てて門戸を清める。
     見届けると南渓に借りができ、[孟仙謡](/ja/people/characters/special831)から託された
     葉家兄妹への手紙入りの包みを渡される。
     この借りは後の滅門ルート・西武林ルートで南渓が唐門に加勢する条件になる
     ([南渓](/ja/people/characters/special829)のページを参照)
     + 武林大会で錦香宮側について上官隼と対抗した場合など、大会での立ち回りに応じた会話差分
     + [葉雲舟](/ja/people/characters/special3)好感≧40：会話差分
     + 処世≦40かつ品性≧60・道徳＜40・処世＜40：それぞれ会話・描写差分
   + **▲ぐっすり朝まで眠る**：[唐默鈴](/ja/people/characters/girl0)が同行かつ想い人が唐默鈴なら唐默鈴好感+2、心相+40。
     夜半に唐默鈴が訪れる場面で👉「山賊になる」(要道徳＜40)：唐默鈴好感+1、道徳+1、弁舌+1 ／「店を開く」：唐默鈴好感+3、心相+10。
     それ以外の同行者は個別の分岐、同行者なしは心相+30
2. **村の若者の噂話**：**🎲天命：村人の見方**(上限80、➕加値：名声)
   + **🧾【＜33】「唐門を支持しない」**：品性≧60または学問≧50なら処世-1、弁舌+1
   + **🧾【＜66】「少しは唐門を支持する」**：心相+10（[唐布衣](/ja/people/characters/brother1)好感≧30なら心相+20、弁舌+1。品性＞40なら心相-10。品性≦40なら心相-20。品性≦40かつ道徳≦40ならさらに心相-10）
   + **🧾【≧66】「唐門の熱狂的支持者」**：心相+20
   + [瑞笙](/ja/people/characters/special999)が武林盟主に選ばれたと知らされる
3. **一同、家路につく (眾人啟程回家)**
   + 性情≦40：団結+2、会話が追加される
   + 分岐：[南宮深](/ja/people/characters/special102)好感≧20、または[崆峒派](/ja/people/factions/kong-tong-sect)の態度が友好、
     または崆峒の掌派人になっている、または[上官螢](/ja/people/characters/girl4)と結縁している → **馬車での見送り**
     (南宮深好感≧20 が最優先で、以降この順に判定される)
   + 上記以外 → **廃寺で雨宿り**
4. **馬車での見送り (馬車送行)**
   + [南宮深](/ja/people/characters/special102)好感≧20：南宮深が馬車を用意する
     + 崆峒派の態度が友好／南宮家が敵対／武林大会の投票結果が敵対：それぞれ会話差分
     + 品性≧40：処世-1、性情+1
     + 品性＜40：処世+1、性情+1
     + 処世＞40：南宮深好感+1
     + 処世≦40：南宮深好感+2
     + 👉「女遊びの世話もしてくれるのか」(処世＞40かつ道徳≦40)：南宮深好感+3
   + 崆峒派の態度が友好：[丹霞子](/ja/people/characters/special404)が馬車を用意する
5. **廃寺で雨宿り (破廟避雨)**：団結+1、心相+10
   + [唐默鈴](/ja/people/characters/girl0)が同行：会話が追加される
   + [龍湘](/ja/people/characters/girl8)を保護している：会話が追加される (学問≧40 で龍湘好感+)
   + [樊嘯天](/ja/people/characters/special4)が唐門に加入している：会話が追加される
   + 休憩画面が開く (セーブ可)
   + 以下のいずれかを選ぶと、終了後に**焚き火の会話**へ進む
     + **▲賭博**：**🎲**(上限30、➕加値：暗器)
       + **🧾【＜50】身ぐるみ剥がされる**：称号「褲を脱いだ侠」を獲得。[唐默鈴](/ja/people/characters/girl0)が同行していると勝った金を分けてくれる (心相+20、銀両+2000)
       + **🧾【＜90】勝ちも負けもなし**：暗器+2
       + **🧾【≧90】まさかの勝ち**：銀両+600×3、団結-1×3
     + **▲腹一杯食べて寝る**：処世+1、心相+20
       + [樊嘯天](/ja/people/characters/special4)が唐門に加入している：心相+10、樊嘯天好感+2
     + **▲目を閉じて思案を沈める**：心相判定
       + 心相≧60：武学+5、修練画面が開く
       + 心相＜60：影響なし
6. **焚き火の会話**：団結-2
   + 腹一杯食べて寝ていた場合：会話と描写に差分
   + 処世≧60：「性別すら間違える」会話差分
   + 皆が大笑いする：団結+2
   + 処世≧40：「姓すら持たない」弁舌+1
   + 道徳≦40：「良い物を食っている」処世+1
   + 品性≦40かつ処世≧60：「もっと下っ端に見える」道徳-1、品性-1、処世+1、弁舌+1
   + 武林大会の投票結果が敵対：会話差分
   + [唐衫](/ja/people/characters/special811)が唐門に加入している：会話が追加される
   + [龍湘](/ja/people/characters/girl8)を保護している：会話が追加される
   + 道徳≧40：品性≧60 で会話が追加される
   + 道徳＜40：処世≧60 で会話差分
   + **古参の外弟子が離脱を考える** → **📖選択**
     + 👉「脅す」：道徳-2、弁舌+1、品性-1、処世+1
     + 👉「言葉を尽くして説得する」：弁舌+1、品性+1、処世-1 → **🎲どう応じるか**(上限50、➕加値：弁舌)
       + **🧾【＜70】言葉に詰まる**
       + **🧾【≧70】説得力十分**：団結+1
     + 👉「引き留めるより歌おう」：処世+2、性情+1、品性+1、心相+10
       + [唐默鈴](/ja/people/characters/girl0)が同行し、想い人が唐默鈴の場合：唐默鈴好感+2、心相+20
7. ➡️ 唐門到着後は[唐門への帰還](/ja/event/detailed_description/3-11-1-回到唐門)(第三年11月上旬)へ続く
