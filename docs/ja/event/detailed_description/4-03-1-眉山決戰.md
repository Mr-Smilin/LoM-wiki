# {{ $frontmatter.title }}

[東西武林盟会戦](/ja/event/detailed_description/4-02-2-東西武林盟會戰)の続き。西武林盟ルートの最終決戦。

## 基本の流れ

**カテゴリ**：メインシナリオ<br>
**発生時期**：第4年3月上旬 決戦当日<br>

1. **決戦当日早朝：**
    - 幼き日の夢を見て、決戦前に掌門と会う：
        - [唐布衣](/ja/people/characters/brother1)が唐門にいる：対話差分
        - 性情 ≦40：対話差分
        - 処世 ≧60：対話差分
        - 道徳 ≧60：対話差分
        - [唐錚](/ja/people/characters/brother2)好感度 ≧40：対話差分
    - 正心堂で師兄が見送り：在門の師兄([唐布衣](/ja/people/characters/brother1)・[唐陞](/ja/people/characters/brother3)・[唐惟元](/ja/people/characters/brother4))により対話差分。猴児酒を持ち去ると追加対話。品性 ≦40で対話差分。
    - 練功場で師弟が見送り：在門の師弟([唐大鯨](/ja/people/characters/big_shock1)・[唐衫](/ja/people/characters/special811))により対話差分。<Girl8Icon>龍湘</Girl8Icon>が同行し錦香宮が西武林盟を支援していれば、華仙児との対話差分。
    - 結縁対象の同行：複数結縁時は1名のみ同行(優先順位：<Girl0Icon>唐默鈴</Girl0Icon>＞<Girl5Icon>夏侯蘭</Girl5Icon>＞<Girl8Icon>龍湘</Girl8Icon>)。結縁対象ごとに対話差分。
    - 西武林盟に加入した各派の代表が随行：
        - 第一幕(外堡)：峨嵋派([向無憂](/ja/people/characters/special408)・[解無塵](/ja/people/characters/special808))、青城派([鄒博](/ja/people/characters/special201)または青城派長老・飛煙子)、崆峒派([丹霞子](/ja/people/characters/special404)・魏菊)
        - 第二幕(結縁対象と渓を渡る)
        - 第三幕(山道)：飛石幫([石公遠](/ja/people/characters/special7)夫婦)、丐幫([李富貴](/ja/people/characters/special809)・[樊嘯天](/ja/people/characters/special4))
    - 武林盟主[瑞笙](/ja/people/characters/special999)と対面：<Girl0Icon>唐默鈴</Girl0Icon>と結縁していない場合、対話差分
    - 結縁対象が同行していれば、決戦前に激励される
    - 決戦前に[瑞笙](/ja/people/characters/special999)と対話：処世 ≧60、道徳 ≧60でそれぞれ対話差分

2. **§眉山決戦：🆚 決鬥：武林盟主[瑞笙](/ja/people/characters/special999)**：
    - 特殊システム：
        - 双方ともHPが一定値(約50%)以下になると特殊対話が発生し、気力+20。
        - 結縁対象が同行していれば、根性(HP0到達時に一度だけHPが回復)が最大1回発動。
        - 嘴攻撃使用時にも特殊対話あり。
    - **勝利**：➡️３．§戦勝へ
    - **敗北**：➡️４．§戦敗へ

3. **§戦勝：**
    - **📖選択：「これほど悪い事をしといて、体裁など？死ね！」**：[瑞笙](/ja/people/characters/special999)を刺殺、黒幕化なし
        - 道徳＜40【悪人、極悪】：主人公は武林盟主にならない(エンディング前のシナリオが盟主になった場合と大きく異なる)
    - **📖選択：「誰かが責任を取らねばならん。」**：[瑞笙](/ja/people/characters/special999)の零の鎮魂曲、黒幕化あり
    - **📖選択：「遺言があるか？」**：[瑞笙](/ja/people/characters/special999)が已むを得ない事情を語り、選択肢が発生
        - **📖選択：「罪を功で贖うべきだ。」**：[瑞笙](/ja/people/characters/special999)を見逃す、武林盟が降伏を認める、黒幕化なし
        - **📖選択：「お前は選択をした、その責任を負うべきだ。」**：➡️「誰かが責任を取らねばならん。」と同じ、黒幕化あり
    - 黒幕化(「誰かが責任を取らねばならん。」または「お前は選択をした、その責任を負うべきだ。」を選んだ場合)：[唐布衣](/ja/people/characters/brother1)が唐門にいれば対話差分
    - 武林盟主の辞退：
        - 道徳が悪人以下でかつ「これほど悪い事をしといて、体裁など？死ね！」を選んだ場合：素行を非難され盟主になれない
        - 上記以外：主人公が自ら盟主を辞退
    - [唐惟元](/ja/people/characters/brother4)の在否で対話差分
    - 結縁対象により対話差分(複数結縁時は優先順位：<Girl0Icon>唐默鈴</Girl0Icon>＞<Girl8Icon>龍湘</Girl8Icon>＞<Girl5Icon>夏侯蘭</Girl5Icon>)
    - 「罪を功で贖うべきだ。」を選び、かつ<Girl0Icon>唐默鈴</Girl0Icon>と結縁していない場合：<Girl0Icon>唐默鈴</Girl0Icon>が唐門に戻る
    - 風雲史《武林の伝説》達成
    - 結縁した相手により結末が分岐(複数結縁時の優先順位：<Girl0Icon>唐默鈴</Girl0Icon>＞<Girl8Icon>龍湘</Girl8Icon>＞<Girl5Icon>夏侯蘭</Girl5Icon>)：
        - <Girl0Icon>唐默鈴</Girl0Icon>：<EndIcon no="48">汗青書 48：武林の伝説</EndIcon>(<AchievementIcon :size="`small`" :no="`13`">唐門の女婿</AchievementIcon>)
        - <Girl8Icon>龍湘</Girl8Icon>：<EndIcon no="48">汗青書 48：武林の伝説</EndIcon>(<AchievementIcon :size="`small`" :no="`14`">忘憂の俠侶</AchievementIcon>)
        - <Girl5Icon>夏侯蘭</Girl5Icon>：<EndIcon no="48">汗青書 48：武林の伝説</EndIcon>(<AchievementIcon :size="`small`" :no="`12`">雪山派の大弟子</AchievementIcon>)
        - <Girl2Icon>葉雲裳</Girl2Icon>が想い人(v1.0.5000以降)：<EndIcon no="48">汗青書 48：武林の伝説</EndIcon>(<AchievementIcon :size="`small`" :no="`18`">魔王の爪牙</AchievementIcon>)
        - 上記いずれとも結縁していない：<EndIcon no="48">汗青書 48：武林の伝説</EndIcon>

4. **§戦敗**：結縁対象により対話差分：<EndIcon no="47">汗青書 47：君が願いし、江湖の道</EndIcon>
