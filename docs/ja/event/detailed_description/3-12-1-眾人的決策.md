## 関連項目
- 本記事は4年目の物語の行方を決める、複数イベントにまたがる流れの攻略である。
- 3年目12月上旬に唐門が武林盟の檄文への対策会議を開くイベントの内容説明は[武林盟への対策](/ja/event/simple/3-12-1-武林盟對策)を参照。

## 基本流程
**カテゴリ**：メインシナリオ<br>
**発生時期**：第3年12月上旬 最後の行動直前<br>

## 1、衆人の意見を尋ねる
1. 衆人の意見を尋ねる：
   + **📜議題：(離開)房間に戻って思考を深める**：
     + [李富貴](/ja/people/characters/special809)好感度≧20、丐幇好感度≧2：[李富貴](/ja/people/characters/special809)がその夜に訪ねてきて唐門に加入し、**⏭️[２－１、西武林盟成立の決断](#_2-1、西武林盟成立の決断)**
     + 金烏上人が死亡 ([金烏上人の死](/ja/people/characters/special207_death))、戦術スキル≧8または戦術スキル≧5・学問≧60：**⏭️[２－１、西武林盟成立の決断](#_2-1、西武林盟成立の決断)**
     + 以上の条件を満たさない：**⏭️[２－２、西武林盟成立不可の決断](#_2-2、西武林盟成立不可の決断)**
     + また、[福韞](/ja/people/characters/special206)の好感度≧20で、福韞が死亡していない ([一時の平穏](/ja/event/simple/3-02-1-一波暫平)を参照) 場合、福韞も唐門に加入する (西武林盟が成立するかどうかには影響しない)。[東西武林盟会戦](/ja/event/detailed_description/4-02-2-東西武林盟會戰)では十八銅人が山道を守る。
   + **📜議題：(雑談)**：唐門の師兄弟、唐門にいる女性キャラ、[樊嘯天](/ja/people/characters/special4)を訪ねる。各議題の条件と増減は[皆の知恵を集める](/ja/event/simple/3-12-1-集思廣益#意見徵詢)を参照。

## ２－１、西武林盟成立の決断
1. **📜議題：(事件)決定：我らも武林盟を結成する**のみ。
   + 🚧未実装：**📜議題：(事件)決定：泥教と同盟を結ぶ**(議題の開放条件：泥教好感度≧10)：師兄たちと泥教の話をしたあと、議題の選択に戻る。同じ会話 (より長い元の版) は、救いようのないルート ([掌門の手配](/ja/event/simple/1-06-1-掌門的安排)を参照) の唐門会議で「いっそ本当に魔教に寝返る」を選ぶと見られる。
2. 丐幇(新派)、青城派、峨嵋派、崆峒派の説得結果に基づいて後のストーリー分岐：
   + 上記4派のいずれか1つ以上の支援を得た：第4年2月中旬開始前に<span style='color: Yellow;'><strong>西武林盟</strong></span>ストーリーラインに入り、第4年2月中旬、残り2回の行動時に[西武林大会](/ja/event/detailed_description/4-02-2-東西武林盟會戰)を実施してから[東西武林盟会戦](/ja/event/detailed_description/4-02-2-東西武林盟會戰#_4、会戦収尾)を開始する。
   + どの派からも支援を得られない：第4年2月中旬開始前に<span style='color: #DC0000;'><strong>徹底抗戦</strong></span>ストーリーラインに転入、第4年2月中旬残り2回の行動時に[唐門囲攻戦](/ja/event/detailed_description/4-01-2-唐門圍攻戰)を開始する。
   + 各派がどちらを支援したかの効果は、東西武林盟会戦については[東西武林盟会戦](/ja/event/detailed_description/4-02-2-東西武林盟會戰)、唐門の包囲については[唐門囲攻戦](/ja/event/detailed_description/4-01-2-唐門圍攻戰)を参照。

### 四師兄の出使
四師兄([唐惟元](/ja/people/characters/brother4))が唐門に戻っている場合 (第3年8月上旬の唐門会議で[四師兄、商いの長旅へ](/ja/event/detailed_description/3-08-1-四師兄遠遊經商)の条件を満たし、第3年11月上旬の最後の行動時に戻ってくる)、第3年12月中旬～下旬に正心堂へ行くと、彼に何をさせるかを選べる (各選択肢の条件と会話は[四師兄が使者に立つ](/ja/event/simple/3-12-2-四師兄出使#目的地選擇)を参照)：
+ 崆峒派、青城派、丐幇大義分舵、各地の中小門派への出使から1つ選ぶ。
+ 家に残る：[唐惟元](/ja/people/characters/brother4)好感度+3、「甘蔗」を獲得。
+ 峨嵋派への出使：[唐惟元](/ja/people/characters/brother4)は行きたがらない。

### 丐幇(新派)の説得
1. [李富貴](/ja/people/characters/special809)が唐門に加入した場合、第3年12月中旬～下旬の期間中、修練場で[李富貴](/ja/people/characters/special809)と会見する (行かなければ丐幇は支援しない)。
2. 第4年1月中旬行動前に、丐幇から知らせが届き、[李富貴](/ja/people/characters/special809)は別れを告げて下山する。<span style='color: Yellow;'>丐幇は西武林盟を支援</span>。
3. [西武林大会](/ja/event/detailed_description/4-02-2-東西武林盟會戰)の際に[李富貴](/ja/people/characters/special809)は帰還する。
+ [李富貴](/ja/people/characters/special809)が唐門に加入していない場合：<span style='color: Red;'>[李富貴](/ja/people/characters/special809)は武林盟を支援する。</span>

### 峨嵋派の説得
+ **出使条件**：無し。
+ **福韞が出使する場合**：
  1. [福韞](/ja/people/characters/special206)が唐門に加入している (条件は上の「1、衆人の意見を尋ねる」を参照)。
  2. 第3年12月下旬行動前に、[福韞](/ja/people/characters/special206)が峨嵋派に出使する。
  3. 第4年1月中旬行動前に、[福韞](/ja/people/characters/special206)が帰還し、道徳+2、<span style='color: Yellow;'>峨嵋派は西武林盟を支援</span>。
+ [福韞](/ja/people/characters/special206)が唐門に加入していない場合、第4年1月上旬行動前に、[唐衫](/ja/people/characters/special811)と唐嬌嬌が唐門に加入しているかどうかに応じて、以下のいずれかの組が派遣される：
  + **唐衫と唐嬌嬌が出使する場合**：
    1. [唐衫](/ja/people/characters/special811)が唐門に加入しており、唐嬌嬌も唐門に加入している ([峨眉の女傑 狄傲](/ja/event/simple/2-05-1-峨嵋狄傲)を参照)。
    2. 第4年1月中旬行動前に、[唐衫](/ja/people/characters/special811)が帰還し、**🎲天命：峨嵋派出使の結果......**(上限99、加値：峨嵋派好感度x5)：
       + **🧾【＜60】半分成功**：<span style='color: Orange;'>峨嵋派は両派いずれも支援しない</span>。
       + **🧾【≧60】成功**：心相+30となり、<span style='color: Yellow;'>峨嵋派は西武林盟を支援</span>。
    3. いずれの結果でも、唐嬌嬌は峨嵋の掌門を殴った罰として半年の面壁を命じられ、唐門を去る。[臥雲崗イベント](/ja/event/simple/3-01-2-臥雲崗事件)で[唐衫](/ja/people/characters/special811)を大師兄に同行させており、かつ武林大会で[唐衫](/ja/people/characters/special811)を受け入れた場合、続けて**🗡️対戦：[唐衫](/ja/people/characters/special811)**：
       + 敗北：武学+2。
       + 勝利：武学+4、**📖選択：奥義は『忘形篇』にある。**を選ぶと性情+1・処世+1、秘笈『雷神腳』を獲得する。
  + **唐衫が単独で出使する場合**：
    1. [唐衫](/ja/people/characters/special811)が唐門に加入しており、唐嬌嬌が唐門に加入していない。
    2. 第4年1月中旬行動前に、[唐衫](/ja/people/characters/special811)が帰還し、**🎲天命：峨嵋派出使の結果......**(上限50、➕加値：峨嵋派好感度x5、団結)：
       + **🧾【＜60】説得失敗**：<span style='color: Red;'>峨嵋派は武林盟を支援</span>。
       + **🧾【≧60】半分成功**：<span style='color: Orange;'>峨嵋派は両派いずれも支援しない</span>。[解無塵](/ja/people/characters/special808)好感度≧30の場合、[解無塵](/ja/people/characters/special808)が唐門に加入。
  + **三師兄が自ら出使する場合**：
    1. [唐衫](/ja/people/characters/special811)が唐門に加入していない。
    2. 出発前に、[唐陞](/ja/people/characters/brother3)が掌門令牌を身に付けていくか、一時的に主人公に預けるかを決める (🎲天命と増減は[峨嵋への使者選び](/ja/event/simple/4-01-1-出使峨嵋人選#三師兄出使)を参照)。
    3. 掌門令牌を一時的に獲得した場合、第4年1月上旬残り1回の行動時に**📖選択：特訓（戦役）**、**📖選択：罠を張る** (東西武林会戦に影響)、**📖選択：好きに過ごす**を選べる ([迎撃の準備](/ja/event/simple/4-01-1-迎戰準備)を参照)。
    4. 第4年1月中旬行動前に、三師兄が帰還し、心相-30 (<Girl0Icon>小師妹</Girl0Icon>と結縁している場合はさらに+20)、**🎲天命：向無憂の態度......**(上限：唐嬌嬌が唐門にいる場合99、いない場合70、➕加値：峨嵋派好感度x5)：
       + **🧾【＜50】両派いずれも支援しない**：<span style='color: Orange;'>峨嵋派は両派いずれも支援しない</span>、[解無塵](/ja/people/characters/special808)好感度≧30の場合。[解無塵](/ja/people/characters/special808)が唐門に加入。
       + **🧾【≧50】説き伏せた**：心相+30、<span style='color: Yellow;'>峨嵋派は西武林盟を支援</span>。

### 青城派の説得
+ **出使条件**：
  + [唐芳](/ja/people/characters/special832)が出使：青城に留学している。
  + [唐惟元](/ja/people/characters/brother4)、普通弟子が出使：青城に留学しておらず、かつ第3年1月中旬の[臥雲崗イベント](/ja/event/simple/3-01-2-臥雲崗事件)で大師兄と一緒に下山しない (申屠龍に会わない)。
+ **唐芳が出使する場合**：
  1. 第3年12月中旬の[西武林盟の成立](/ja/event/simple/3-12-2-西武林成立)時に、[唐芳](/ja/people/characters/special832)が自動的に青城派に出使する。
  2. 第4年1月下旬行動前に、[唐芳](/ja/people/characters/special832)が帰還し、<span style='color: Yellow;'>青城派は西武林盟を支援</span>。
     + 臥雲崗イベントで大師兄と一緒に下山しておらず、[申屠龍](/ja/people/characters/special405)好感度≧30で、かつ崆峒掌派人になっていない場合：決戦前に下山したとき、[申屠龍](/ja/people/characters/special405)を訪ねて手合わせできる。
+ **四師兄が出使する場合**：
  1. 第3年12月中旬に、[唐惟元](/ja/people/characters/brother4)を青城派に出使させる (上の「四師兄の出使」を参照)。
  2. 第4年1月下旬行動前に、[唐惟元](/ja/people/characters/brother4)が帰還し、**🎲天命：青城派出使の結果......**(上限60、➕加値：団結、青城派好感度x5)：
     + **🧾【＜40】失敗した**：心相-20、処世≧60の場合は弁舌+1、結果は普通弟子が出使した場合の「態度は曖昧だ」と同じ。
     + **🧾【≧40】成功した**：心相+10、<span style='color: Yellow;'>青城派は西武林盟を支援</span>。
+ **普通弟子が出使する場合**：
  1. 第3年12月下旬行動前に、誰も青城派に出使していない場合、[唐陞](/ja/people/characters/brother3)が普通弟子を青城派に出使させる。
  2. 第4年1月下旬行動前に、普通弟子が帰還し、**🎲天命：青城派出使の結果......**(上限50、➕加値：団結、青城派好感度x5)：
     + **🧾【＜60】期待するな**：<span style='color: Red;'>青城派は武林盟を支援</span>。
     + **🧾【60～89】態度は曖昧だ**：青城派長老の[懐素道人](/ja/people/mobs/orthodox-sects#懐素道人)が十数名の弟子を連れて西武林盟を支援し、[申屠龍](/ja/people/characters/special405)が武林盟を支援する。
     + **🧾【≧90】支援**：<span style='color: Yellow;'>青城派は西武林盟を支援</span>。
+ **出使条件を満たさない場合**：
  1. 第3年12月下旬行動前に誰も青城派に出使できないというイベントが発生し、<span style='color: Orange;'>青城派は両派いずれも支援しない</span>。

  2. 第4年1月下旬行動前に、音信が途絶えており、<span style='color: red;'>崆峒派は武林盟を支援</span>。

### その他の門派
主要なストーリー分岐には影響しない。丐幇大義分舵・飛石幇・錦香宮は、[東西武林盟会戦](/ja/event/detailed_description/4-02-2-東西武林盟會戰)の天命ダイスの加減値に影響する。
+ **中小門派**：
  + **四師兄が出使する場合**：
    1. 第3年12月中旬～下旬に、[唐惟元](/ja/people/characters/brother4)を各地の中小門派に出使させる (上の「四師兄の出使」を参照)。
    2. 第4年1月下旬行動前に、[唐惟元](/ja/people/characters/brother4)が帰還し、心相+20、団結+2。
  + **普通弟子が出使する場合**：
    + 誰も中小門派に出使していない場合、第4年1月下旬開始前に普通弟子が帰還し、**🎲天命：中小門派の返答......**(上限50、➕加値：名声)：
      + **🧾【＜60】収穫なし**：心相-20、団結-2。
      + **🧾【＜80】様子見**：心相-10。
        + 道徳≦40【悪人、極悪】の場合、追加品性-1、団結+1、[唐陞](/ja/people/characters/brother3)好感度+1。
      + **🧾【≧80】返答を得た**：心相+20、団結+2。

+ **丐幇(大義分舵)**
  + **出使条件**：[李富貴](/ja/people/characters/special809)が唐門に加入していない、丐幇好感度≧5。
  1. 第3年12月中旬～下旬に、[唐惟元](/ja/people/characters/brother4)を丐幇大義分舵に出使させる (上の「四師兄の出使」を参照)。
     + [樊嘯天](/ja/people/characters/special4)が唐門に加入している場合、[唐惟元](/ja/people/characters/brother4)は[樊嘯天](/ja/people/characters/special4)を同伴して出使する。
  2. 第4年1月中旬行動前に、[唐惟元](/ja/people/characters/brother4)が帰還し、**🎲天命：丐幇大義分舵への訪問......**(上限50、➕加値：丐幇好感度x5、名声)、基準値：[樊嘯天](/ja/people/characters/special4)を同伴して出使した場合は30、[唐惟元](/ja/people/characters/brother4)が単独で出使した場合は50：
     + **🧾【基準値未満】失敗**：大義分舵は解散し、心相-20。
       + [樊嘯天](/ja/people/characters/special4)を同伴して出使した場合、[唐惟元](/ja/people/characters/brother4)は[樊嘯天](/ja/people/characters/special4)の犬が何匹も打ち殺されたと言い、[樊嘯天](/ja/people/characters/special4)は後山で埋葬し、主人公は行くように言われるが、実際に後山に行ってもイベントはない。
