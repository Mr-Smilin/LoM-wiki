## [【MOD 作者の方へ】回想(Log)機能を再実装しました](https://store.steampowered.com/news/app/1859910/view/674009530499072034?l=tchinese)

公開日  
2026年10月27日 火曜日

今回のアップデート(v1.0.6001.0)で回想インターフェースを作り直しました。Fungus の NarrativeLog をベースにしていた従来の回想インターフェースは削除されています。  
新しい回想では、シナリオの台詞に加えて、数値・好感度・スキルなどの変化も記録し、セーブデータに書き込みます。  
従来の回想機能を使っている MOD は、無効になる、エラーが出る、表示が崩れるなどの不具合が起きる可能性があります。MOD 作者の方は、以下の説明を参考にご自身で更新してください。  

### 削除したもの

1. シナリオシーンの MainUI にあった旧回想画面のオブジェクト NarrativeLog
2. シーン内の Fungus NarrativeLogMenu
3. `ToggleNarrativeLogView()` は使用できなくなりました。
4. `FindObjectOfType<NarrativeLogMenu>()` を使うと null が返ります。
5. `Mortal.Story.StoryManager` のメンバー：
    - フィールド：`_narrativeLogMenu`、`_narrativeLog`、`_narrativeView`、`_logCloseButton`
    - メソッド：`WaitForLogCanvas()`
    - リフレクションでこれらのフィールドにアクセスすると null が返ります。このメソッドへの Harmony パッチは失敗します。

### 変更したもの

1. 回想インターフェースを新しい `Mortal.Core.StoryLogPanel` に変更しました。ストーリーシーン(Story)と養成シーン(Free)のどちらでも開くことができ、ショートカットキーも従来どおり回想キーです。
2. 回想データは `Mortal.Core.StoryLogData` が管理し、セーブデータに書き込まれます。
3. `StoryManager.Log(bool)` / `ToggleLogButton(bool)` の名前は変わりませんが、内部の動作は新しいパネルの開閉に変わりました。この2つのメソッドにパッチを当てていた MOD は、改めて動作を確認してください。
4. `StoryMainUI.DisplayRelationshipModification` の引数を `(Sprite, int)` から `(RelationshipStat, int)` に変更しました。
5. 画面に表示される数値・好感度・スキル・道具・風雲史・敵勢力の通知・message のシナリオメッセージは、回想にも同時に書き込まれるようになりました。Harmony の prefix で `StoryMainUI` のこれらの Display メソッドをスキップしている MOD では、対応する記録が消えます。`DisplayMessageText(string)` は回想に書き込まれません。
6. Fungus の `FungusManager.Instance.NarrativeLog` コンポーネントは引き続き存在し、会話を記録します。これを読み取る MOD はそのまま使えます。ただし、このコンポーネントはどの画面にも表示されなくなったため、`NarrativeLog.AddLine()` で追加した内容はプレイヤーに見えません。

### 新しい書き込み方法

Mortal.Core.dll を参照に追加すれば使えます：

```csharp
using Mortal.Core;
// テキスト記録：そのまま表示し、セーブデータには書き込まない(MOD ではこちらを推奨)
StoryLogData.AddText("表示するテキスト", false);
// Unity Rich Text に対応
StoryLogData.AddText("<color=#FFD700>MOD メッセージ</color>", false);
// 多言語メッセージ：回想を開いたときに現在の言語に合わせてテキストを組み立てる
// StoryLogArg.FromKey は言語ごとに翻訳され、FromValue は値をそのまま表示する
StoryLogData.AddMessage("MyMod/Format/Gain", false,
    StoryLogArg.FromKey("MyMod/Item/Sword"),
    StoryLogArg.FromValue("3"));
// 現在のすべての記録を読み取る(読み取り専用)。回想インターフェースと同じテキストが得られる
ILocaleResolver resolver = LocalizationManager.Instance.LocaleResolver;
foreach (StoryLogEntry entry in StoryLogData.Entries)
{
    // 記録が使う KEY が存在しない場合は false を返し、回想インターフェースにもこの項目は表示されない
    if (StoryLogFormatter.TryGetContent(entry, resolver, out string content))
    {
        // entry.Type：記録の種類。entry.Key の意味は種類によって異なる
        // entry.IsSave：セーブデータに書き込むかどうか
    }
}
```

シナリオスクリプト(Lua)では `luamanager.AddStoryLogText("テキスト")` を使えます。効果は `AddText(text, false)` と同じです。

### 注意事項

1. `isSave = false` を優先して使ってください。セーブデータに書き込まれた記録は、MOD を外すと非表示になりますが、データ自体はプレイヤーのセーブデータに残ります。  
   `AddText` のテキストは多言語化できず、`isSave` に `true` を渡してもセーブデータには書き込まれません。セーブデータに書き込みたい場合は、`AddMessage` と言語 KEY を組み合わせて使ってください。
2. シナリオ MOD では、`luamanager.AutoSave()` と `luamanager.ToggleSaveButton(1)` をスクリプトの冒頭、台詞や数値変化より前に置いてください。そうしないと、ロード後にこれらの記録が回想の中で重複して現れます。
3. 回想は最大300件まで保持し、超えると古いものから順に削除されます。
4. セーブデータに書き込まない記録は、ロード後に消去されます。
5. 以上は正式な MOD API ではなく、今後のバージョンで調整される可能性があります。
