# 日本語化MOD 版別変更点

活俠傳に公式の日本語版はなく、本 wiki の用語は非公式の日本語化MOD
([LOM-JPMOD](https://dlaqe2334.github.io/LOM-JPMOD/) /
[GitHub](https://github.com/Dlaqe2334/LOM-JPMOD)) の訳を優先しています。
MOD は版が上がるたびに訳語を見直しているため、**古い版でプレイしていると本 wiki の表記と
食い違って見えることがあります**。このページはその照合用に、版ごとの主な変更点をまとめたものです。

- 訳語の一覧そのものは [用語対訳表](/ja/glossary) を参照してください
- MOD 公式の変更履歴ではなく、各版に同梱された翻訳データを比較して確認できた範囲です。
  網羅ではありません

### 訳文

v2.2 の時点と比べると、ルビを別にしても 1万4千箇所あまりの訳文が変わっています。
そのうち本 wiki の表記に関わるものは下の「v2.3〜v2.4 の訳語変更」にまとめています。

## v2.3 (2026年7月19日)

### ルビ機能の追加

漢字に振り仮名を表示する機能が追加されました。ゲーム中のキー操作で切り替えられます。

- **F7**: 全表示 → 初出のみ → OFF の順に切り替え (次の文章から反映)
- **Ctrl + F7**: 「初出のみ」の記録をリセット
- **F5**: 話者名の上の常時ふりがな表示を切り替え
- 話者名・別号・選択肢などは、マウスを重ねると読みが表示されます (F7 が OFF の時は非表示)

### 武功・施設・装備名の改称

| v2.2 以前 | v2.3 以降 |
| --- | --- |
| 核棗釘 | 棗種矢 |
| 稽古塔 | 練功塔 |
| 密密縫 | 密々綴 |
| 敏腕郎中 | 辣眼郎中 |

### 「侠」の字体の統一

v2.2 では「侠」と「俠」が混在していましたが、v2.3 で「俠」に統一されました
(群俠、俠客、唐二俠 など)。

### 翻訳データの保管方式の変更

翻訳データの保管方式が変わり、`Mods/JP/Stringtable.csv` は中身のないファイルになりました。
訳文の実体は暗号化された別ファイルに移っています。
