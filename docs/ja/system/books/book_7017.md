## 入手方法

- 青城留学中の第2年11月上旬に段智秀と対面した際、煉薬の総消費ポイント>60、【あの手紙】を選択した後、更に【黒幕】を選択して獲得。順序を変えてはいけません。

## 備考

- 大理段氏の天龍訣、枯栄神功。この掌力は陰陽両属を揉和し、離時は相生相引、合時は相剋相斥し、まるで二匹の龍のようだという。
- 枯栄神功第三重境界 - 滅・諦・掌！
- 非常に面倒な武功なので、丹薬と組み合わせて陰陽を調整してください。
  1服あたり[穿心龍膽湯](/ja/system/pills)で陰陽-10、[南蝥礜石散](/ja/system/pills)で陰陽+10。
  入手時点では陰陽が高いことが多い(このルートで修練する
  [温陽活血符](/ja/system/books/book_8100)が陰陽≧60を要求するため)ので、
  まずLV3の陰陽<40まで下げる分の丹薬を用意しておくとよい。
- 表内の内功、体力は記入を間違えていない。実際に上がったり下がったりする。
