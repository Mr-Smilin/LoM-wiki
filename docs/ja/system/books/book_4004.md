# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="4004"></BookItemIcon>

<ruby>武林盟<rt>ぶりんめい</rt></ruby>主大俠龍淵の七種の成名絶技の一つ。
<br><br>
<ruby>玄玄如意<rt>げんげんにょい</rt></ruby>、妙手空空、素手で人の兵器を受け止め、人の懐を探り、不利なることなし。
<br><br>
<ruby>龍淵<rt>りゅうえん</rt></ruby>は少年時代、この技で人の金品を盗むことが少なくなかったが、覚醒して成長し、<ruby>武林<rt>ぶりん</rt></ruby>の命運を一身に担うようになってから、<ruby>秘笈<rt>ひきゅう</rt></ruby>から盗みの手法を削除した。
