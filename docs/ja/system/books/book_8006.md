<ruby>江湖<rt>こうこ</rt></ruby><ruby>鬼蜮<rt>きよく</rt></ruby><ruby>録<rt>ろく</rt></ruby>の匿名被害者が、口で筆を咥えて書いた陳情録である。<br><br>書中では、彼がいかにして天真爛漫で四肢健全な子供から、詐欺により家族を失い、異郷を流浪し、自活を図るも盗みの濡れ衣を着せられ、投獄され両腕を斬られたかが述べられている。<br><br>最終的に彼は脱獄を果たし、獄中で苦練した <ruby>棗種矢<rt>なつめだねのや</rt></ruby>で復讐を遂げた。
