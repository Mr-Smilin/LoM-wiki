# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="2302"></BookItemIcon>

<ruby>点蒼<rt>てんそう</rt></ruby>派万里に一人の弟子のみが、破格で<ruby>剣廬<rt>けんろ</rt></ruby>に三日間入ることを許され、<ruby>点蒼<rt>てんそう</rt></ruby>剣聖が<ruby>剣廬<rt>けんろ</rt></ruby>に残した三式の剣意を参悟できる。三招の剣意は各々奥義を持ち、優劣なく、一つを得れば<ruby>江湖<rt>こうこ</rt></ruby>を独歩するに足るが、十中八九、十日半月住んでも何も得られぬ者ばかりである。
<br><br>
<ruby>葉雲裳<rt>よううんしょう</rt></ruby>は好奇心に駆られて忍び込んで遊んでいたが、すぐに引きずり出された。彼女は<ruby>武功<rt>ぶこう</rt></ruby>を会得していなかったが、聡明絶頂にして型に嵌まらず、その僅かな時間で何かを悟ったようだったが、年が若すぎて朧げであった。今日の訣別にて、初めて離愁の味を知り、往事が心に湧き上がり、豁然として頓悟し、この招を書き記した。
<br><br>
一式のみなれど、残念は無窮[^1]であり、この剣こそ剣聖第四極招――「魂遊故里芳盈袖、春啼曉、莫挽留」である。
