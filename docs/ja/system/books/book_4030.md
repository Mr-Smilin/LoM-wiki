# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="4030" />

<ruby>丐幇<rt>かいほう</rt></ruby>の者たちが約定成俗とする逃走技巧。人数が多い時に使えば非常に壮観で、一斉に散開し、四方八方へ奪路して逃げる。心に<ruby>霊犀<rt>れいさい</rt></ruby>ありと如く東を指して西に走り、敵に一網打尽にされることなく、最終的には必ず網を逃れた魚が家に帰って通風報信できる。
<br><br>
この逃法は<ruby>歌訣<rt>かけつ</rt></ruby>の形式で伝唱される。歌に<ruby>曰<rt>いわ</rt></ruby>く「眼は東辺を看て西辺を走り、逃げ場無くば樹顛に上る、三五成群鉄の命、生死に数あり牽を拖くこと莫れ」。詞は俗俚浅白なれど、詭道のみならず、万一落網した時の心理建設まで事前に為している。
