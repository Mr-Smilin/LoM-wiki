# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="7012"></BookItemIcon>

<ruby>南宮<rt>なんきゅう</rt></ruby>家が世代承伝する家学の心法。人手一本、<ruby>歌訣<rt>かけつ</rt></ruby>は大方に書本の内頁に抄録されている。
<br><br>
<ruby>道家<rt>どうか</rt></ruby>思想を揉合し、万変猶お定まり、神怡び気静まり、意は玄関を守り、邪気を降伏し、虚懐若谷にして、心神清明なり。
<br><br>
心を守るを本とし、而る後に身を護り、家を保ち、国を衛る。これが<ruby>南宮<rt>なんきゅう</rt></ruby>家学の根基である。

## 入手方法

- 囲城イベント－涼んでいるときに南宮遠が碁を打っている場面に出会い、ダイス【🎲≧50 小遣いはやらない】に成功すると手合わせを申し込まれる。
  - 注意：ダイスの補正は道徳がプラス、名声がマイナス。名声の高い悪人は成功しにくい。
  - 手合わせで自分の血量が40%～80%まで減ったときに贈られる。
- 2年10月中旬－[唐惟元](/ja/people/characters/brother4)から購入（$2500）

## 偕老の誓い

- <Girl2Icon>雲裳</Girl2Icon>ルートで技能を発動して救う際、既に南宮護心訣を習得していれば、技能が消滅し、代わりに偕老の誓いを習得する。~~南宮遠からの愛~~
> 伝説によると、かつて[南宮世家](/ja/people/factions/nan-gong-family)と宇文の二大世家は水火のごとく相容れず、二人の奇才――南宮涼と宇文馨――を輩出したという。<br>
> 江南の舟での夜の密会、崑崙に共に登っての孤児救出、合璧しての匪王撃破、峨嵋金頂で肩を並べての夜明けの眺望。<br>
> 本来ならば想いを遂げて結ばれるはずであった……だが当時、唐門の先達「燭骷髏」唐燭が良からぬことをしでかし、二人は再び仇敵として反目し合うこととなった。<br>
> 二人は一族の悲願を背負い、ついにはどちらか一方しか生き残れぬ運命となった。<br><br>
> 激闘の末、二人は双掌を合わせ、内力を競い合った。宇文馨は恬然と微笑むと、内力を密かに南宮涼へ送り込んで傷を癒やし、その掌力を甘んじて受けて命を落とした。<br>
> この陰柔の内力は南宮涼の体内で生々流転して息むことなく、南宮家嫡伝の内息と水乳のごとく交わり一つとなって、あたかも一縷の香魂のように、相護って老いるに至った。<br>
> これこそが[全真剣法](/ja/system/books/book_7002)に通じる南宮心法の最高境地《偕老の誓い》である。

- 偕老の誓い：致命的な攻撃を耐えられ、気力100を回復。
