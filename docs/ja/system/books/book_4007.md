# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="4007"></BookItemIcon>

姿は優美で、絵の中の美人が紙面から躍り出たかのよう。一顰一笑が人の心を奪う。一見すると柔弱で力がなさそうだが、実はその一挙手一投足に精妙な後手が込められており、談笑のうちに相手の<ruby>点穴<rt>てんけつ</rt></ruby>を押さえてしまう。速くもなく、荒々しくもないが、とにかく避けようがなく、百発百中である。
<br><br>
ただし、あなたの御尊顔で中和されるため、命中率は少なくとも半減する。

- 点穴：攻撃命中時、麻痺蓄積値を与える（LV1 10、LV2 15、LV3 20）。
- 折花手：防御時、一定の確率で暗器をガードする（LV1 5%、LV2 10%）。ガードに成功すると、相手に「怯え」を付与する。

## 習得方法

-   <ruby>小竹<rt>しょうちく</rt></ruby>の帰郷－老虎山のふもとの町に着き、小竹が身支度を整える間に、「雑貨の露店がある」を選ぶ（一度だけ選べる）。品性≧40でないと露天商は商売をしてくれない。
-   露天商と話した後の天命ダイスで「武功の秘籍」（70〜84）が出ると、露天商が3000銀で売りつける。銀≧3000で「買う」を選ぶと入手。

## 備考

-   露天商は、この秘笈は叔父が修めた武功で、叔父は修めた後に殺されたと語る。
