# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="7016" />

道門の<ruby>虎嘯功<rt>こしょうこう</rt></ruby>は、猛虎の咆哮を以て譬え、修道の人が勇猛精進し、猛虎の如く威猛であり、群邪を辟易させることを形容する。<br><br>この功は<ruby>丹田<rt>たんでん</rt></ruby>の内気を外発させ、人と交手する際に発功して呼嘯すれば、声は雷霆の如く千里を疾瀉し、人の心魄を奪い、甚だしきは<ruby>内傷<rt>ないしょう</rt></ruby>を造ることすらできる。

- 虎嘯功：境界二以上。口功が「虎嘯吼」に変わり、追加の内功を消費して、口功に実質的なダメージを持たせる。

## 入手方法

青城留学で、以下の条件を同時に満たした後、9月上～11月中に申屠龍から贈られる：
1. 9月下旬までに、3回修練した後に排擠イベントが発動。三五斬妖剣を獲得した後、これを練満する。
2. 申屠龍≧15。修練時に一定確率で彼と切磋できる。最低1回は必要。
