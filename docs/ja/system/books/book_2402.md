# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="2402"></BookItemIcon>

道法将軍・丹霞子の成名絶技だが、実は一揃いの武功ではない。
<br><br>
<ruby>崆峒<rt>こうどう</rt></ruby>が山門を開き派を立てた当初、山中には門派が林立し、暴力と混沌を崇めていた。中でも天竺の「魔僧」鳩摩羅闍と、突厥の「殺星」執失賀魯が最たるものであった。
<br><br>
一人は熔天魔炎剣を、もう一人は呑月蒼狼刀を使った。ちょうど至陽と至陰であり、威力は強いが心法が偏激で、いずれも正派の武功ではなかった。
<br><br>
修める者は功力が深まるほど、性情もまた火のように激しく陰険になっていく。当時この二人のどちらかが崆峒を制覇して威を立て国を築いていたら、中原の版図は今日の姿ではなかっただろう。
<br><br>
幸い初代<ruby>掌派人<rt>しょうはじん</rt></ruby>が彗星のごとく現れて諸々の邪を洗い流し、神雷を呼んで魔功を撃ち砕かせ、崆峒はようやく毎年太平でいられた。
<br><br>
二部の魔功の残頁は風に舞って群山に散らばり、数百年後、<ruby>丹霞子<rt>たんかし</rt></ruby>が誤って<ruby>弾箏湖<rt>だんそうこ</rt></ruby>に落ち、湖の洞窟を経て道すがら残頁を拾い集めて一冊に綴じたところ、奇跡的に二部の魔功が一つに合わさった。しかも雑を去り精を残し、陰陽が相和して、かつての魔典はついに神功となった。

## 習得方法

-   金烏事変で崆峒へ向かう道中、「出発」を選んだとき、[丹霞子](/ja/people/characters/special404)の好感度が30以上なら、夜に丹霞子がこの書を焚き火に投げ込み、趙活が慌てて拾い上げて入手する。好感度が足りなければ、この場面は起きない。
    -   小梅ルート：襄陽行での孟珙の好感度 (1〜4) に応じて丹霞子の好感度+3〜+12。[孟仙謡](/ja/people/characters/special831)の好感度が3以上ならさらに+10。崆峒への道中の雑談と手合わせで最大+9。
    -   小竹ルート：好感度が足りないため、現行版では入手できない。

## 備考

-   [丹霞子](/ja/people/characters/special404)の成名武功。入手時、書の表紙が少し焦げていたが、中身は無事である。
-   入手後、処世が60以上なら趙活がお礼を言い、[丹霞子](/ja/people/characters/special404)の好感度+1。
