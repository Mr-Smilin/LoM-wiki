<ruby>泥教<rt>でいきょう</rt></ruby><ruby>天道<rt>てんどう</rt></ruby>の魔教心法である。<br><br>医書から演変した養生気功の一部で、中医の「温法」を基礎とし、温性、辛性の薬物で穴道を艾灸し、寒気を駆散する。また気を補い血を養うことができ、十分に霊験あらたかで、<ruby>回陽<rt>かいよう</rt></ruby>就逆の効がある。[^1]

## 入手方法

- 1年4月上旬－[唐惟元](/ja/people/characters/brother4)の買物（$1200）

## 備考

[^1]: 「回陽就逆」は MOD 原文ママ。漢方用語としては「回陽救逆」(陽気を回復させ虚脱を救う)。
