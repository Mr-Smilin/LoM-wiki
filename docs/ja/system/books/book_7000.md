# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="7000"></BookItemIcon>

古典的江湖の<ruby>鬼蜮<rt>きよく</rt></ruby>伎倆、多くのゲスが使う。
<br><br>
敵が強大で敵わぬ時、機を捉えて運功し体内経脈を封阻し、<ruby>気血<rt>きけつ</rt></ruby>を凝滞させ、脈搏を一時停止させれば、死んだかのように見える。
<br><br>
敵が去った後、予め掌心に隠した石灰の発熱により自身を喚醒する。
<br><br>
ただしこの<ruby>内功<rt>ないこう</rt></ruby>の使用は危険が高い。万一喚醒の機関が不調なら、醒めた後も脳の酸欠により痴呆となる。また万一狠角色を招いて、汝が倒れるや否や二の句なく刀を二本補われれば、仮死は真死となる。
