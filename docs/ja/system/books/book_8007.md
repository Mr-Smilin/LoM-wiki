# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="8007" />

<ruby>儒家<rt>じゅか</rt></ruby>の戦神・<ruby>孟子<rt>もうし</rt></ruby>が列国を周遊した際、舌戦で<ruby>群雄<rt>ぐんゆう</rt></ruby>を圧倒し、<ruby>唇槍<rt>しんそう</rt></ruby><ruby>舌剣<rt>ぜっけん</rt></ruby>をもって<ruby>中原<rt>ちゅうげん</rt></ruby>を平定した語録である。出典は不明だが、民間伝説では象棋の「炮」とは実は<ruby>孟子<rt>もうし</rt></ruby>の口を指し、隔空殺人が可能で、恐ろしいのは方位さえ定まれば誰でも殺せることだという。<br><br>相手の地位がいかに尊く、教えを請う態度がいかに謙虚であろうと、<ruby>孟子<rt>もうし</rt></ruby>に叱責されることは免れず、彼は論争の際に<ruby>孫子兵法<rt>そんしへいほう</rt></ruby>や<ruby>内功<rt>ないこう</rt></ruby>まで用い、相手に反論の余地を与えず、罵り殺されても不思議ではなかった。<br><br>諸子百家を罵り尽くしながら、他者からの批判は許さず、怒って反駁した「予豈好辯哉！？予不得已也！！」は千古の絶唱となった。

- 嘴炮流の必須武功。敵が1度怒ると、即座に3ターンを制圧できます。
- 【棗種矢】との相性が良好です。
