# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="7003"></BookItemIcon>

<ruby>西域<rt>せいいき</rt></ruby>密宗より伝わる神秘の禅功。習練方法は<ruby>中原<rt>ちゅうげん</rt></ruby>武術と截然と異なり、姿勢が奇怪なだけでなく、遣詞も十分晦渋で、最終二章は<ruby>牛頭<rt>ごず</rt></ruby>不対馬嘴に訳され、読み難い。
<br><br>
この禅功を練るには身体力行を講究し、炭木に点火し、尖鋭な砕石を敷き、石上にて練功する。練功者は必ず<ruby>内功<rt>ないこう</rt></ruby>を潜運し、熱力を体外に排出せねばならぬ。さもなくば必ず引火焼身する。
<br><br>
聞くところによれば最高境地まで修練すれば打坐浮空、手足関節を脱臼伸長して人を打ち、口より烈火を吐けるという。
<br><br>
しかし最後の二章の内容を知らねば、この境地は如何にしても見ることは難しい。
