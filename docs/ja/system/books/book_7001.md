# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="7001"></BookItemIcon>

<ruby>丐幇<rt>かいほう</rt></ruby>の誰もが歌う幇歌蓮花落は、実は生存技巧を講究する一部の<ruby>内功<rt>ないこう</rt></ruby><ruby>歌訣<rt>かけつ</rt></ruby>である。
<br><br>
毎夜仕事を終えた後、輩分の古い乞食が小輩を率いて斉唱し、歌いながら箸で碗を叩き、これにて拍子を掌握し、歌曲に合わせて換気し、<ruby>吐納<rt>とのう</rt></ruby>の習慣が自然に養成される。
<br><br>
ただし歌詞は往々にして粗鄙不堪で、斯文を辱め、娘家に向かって歌えば官に訴えられることもある。
