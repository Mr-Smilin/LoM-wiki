# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="8107" />

正式名称は『黄帝八十一難経』で、著名な医学著作である。『黄帝内経』の疑難と要旨を闡発することを旨とする。<br><br>名医扁鵲の著とされ、「五邪相干」「十変」理論を強調し、五臓の生剋関係を解説する。<br><br>脈学、<ruby>経絡<rt>けいらく</rt></ruby>、<ruby>臓腑<rt>ぞうふ</rt></ruby>から針法に至る論述は、後世の医学に深遠な影響を与えた。
