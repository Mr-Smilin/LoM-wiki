# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="7005"></BookItemIcon>

道門蒼龍吟は、九霄の龍吟に喩え、得道の人が飛昇して清嘯する様が、龍吟が空を破るが如く清らかに響くことを形容したものである。
<br><br>
この功は<ruby>丹田<rt>たんでん</rt></ruby>の内気を外に発し、人と交手する際、功を発して呼嘯すれば、声は雷霆の如く千里を疾瀉し、人の心魄を奪い、甚だしきは<ruby>内傷<rt>ないしょう</rt></ruby>を負わせることさえできる。
