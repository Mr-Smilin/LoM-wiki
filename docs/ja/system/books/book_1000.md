# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="1000"></BookItemIcon>

<ruby>唐門<rt>とうもん</rt></ruby>弟子が一人一冊持つ<ruby>武功<rt>ぶこう</rt>秘笈<rt>ひきゅう</rt></ruby>であり、《毒経》と並ぶ二大秘宝である。
<br><br>
師の伝授する<ruby>心訣<rt>しんけつ</rt></ruby>、運勁の手法なくしては、独学のみでは進展が極めて難しい。
<br><br>
巻頭の《<ruby>忘形論<rt>ぼうけいろん</rt></ruby>》は既に完璧に暗記している。
