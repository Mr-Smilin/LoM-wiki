# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="7010"></BookItemIcon>

現今既に存在しない<ruby>雪山<rt>せつざん</rt></ruby>派の心法。修練方法は非常に特殊である。
<br><br>
<ruby>真気<rt>しんき</rt></ruby>を吸足し、赤身裸体で頭を下に足を上にして雪中に挿し込み、足掌のみを外に露出させる。傍らの者が艾で足底の湧泉穴を炙り、修練者は心法を運使して艾炙の熱力を借りて温経通絡し、体温を調適して氷雪に抵禦する。
<br><br>
雪水がない場合は、近くの清涼な渓流でも代替できる。
