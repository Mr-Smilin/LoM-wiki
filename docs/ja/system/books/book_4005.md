# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="4005"></BookItemIcon>

梵文で書かれた古い指譜。<ruby>蔵経閣<rt>ぞうきょうかく</rt></ruby>の地下深くに秘蔵されており、地震がなければ永遠に日の目を見ることはなかっただろう。
<br><br>
那由他とは<ruby>仏教<rt>ぶっきょう</rt></ruby>の数の概念で、「数え切れないほど多い」という意味である。
<br><br>
劫は<ruby>天竺<rt>てんじく</rt></ruby>の時間の呼称で、成・住・壊・空を経た後が一大劫となる。故にこの功を行うには<ruby>禅機<rt>ぜんき</rt></ruby>を参悟し、不生不滅、色身をもって無限の劫を経て、初めて大道を<ruby>証悟<rt>しょうご</rt></ruby>する。
