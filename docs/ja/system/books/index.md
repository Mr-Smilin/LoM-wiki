## 設定

-   鳥熊は、武功よりも恐ろしいのは流言（噂）であり、人の言葉こそ畏るべきものだと考えている。[^1]
-   どの門派にもそれぞれの特色と信念があり、それが各門派の武功に反映されている。[^1]
-   大部分の武功と内功に強い関連性はなく、むしろ対応する内功がなければ使えない武功の方が少数である。[^2]
-   武芸者が皆筋骨隆々というわけではなく、筋肉がつくと速度が落ちると考える流派もあれば、均衡のとれた鍛錬を重視する流派も多い。[^3]
-   武功が高ければ喧嘩に必ず勝てるというわけではなく、たとえ最強の[趙活](/ja/people/characters/player)であっても、不意を突かれて[虞小梅](/ja/people/characters/girl3)に階段から突き落とされることはあり得る。[^3]

[^2]: PTT C 洽－[\[活俠\] 龍湘+綜合小知識数則](https://www.ptt.cc/bbs/C_Chat/M.1728840738.A.3D7.html)
