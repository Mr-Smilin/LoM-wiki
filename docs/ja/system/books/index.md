## 設定

-   鳥熊は、武功よりも恐ろしいのは流言（噂）であり、人の言葉こそ畏るべきものだと考えている。[^1]
-   どの門派にもそれぞれの特色と信念があり、それが各門派の武功に反映されている。[^1]
-   大部分の武功と内功に強い関連性はなく、むしろ対応する内功がなければ使えない武功の方が少数である。[^2]
-   武芸者が皆筋骨隆々というわけではなく、筋肉がつくと速度が落ちると考える流派もあれば、均衡のとれた鍛錬を重視する流派も多い。[^3]
