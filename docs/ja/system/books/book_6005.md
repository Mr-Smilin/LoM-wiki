# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="6005"></BookItemIcon>

<ruby>伝承<rt>でんしょう</rt></ruby>によると、陥空島五義の一人、「穿山鼠徐慶」が得意とした<ruby>武功<rt>ぶこう</rt></ruby>である。
<br><br>
<ruby>徐慶<rt>じょけい</rt></ruby>は鉄匠出身で、力大無窮、異術を有して地を鑽れるゆえ穿山鼠と称された。五鼠は<ruby>開封<rt>かいほう</rt></ruby>府に帰順し、包拯を輔佐した。
<br><br>
嘉祐七年、包公病逝し、翌年合肥に帰葬された。五鼠は一路相送し、叩首拝別して、各々東西に奔った。
<br><br>
その後、<ruby>徐慶<rt>じょけい</rt></ruby>は<ruby>崆峒<rt>こうどう</rt></ruby>に帰隠し、<ruby>鉄臂神拳<rt>てっぴしんけん</rt></ruby>と鉄匠技術を伝え、<ruby>鉄拳巷<rt>てっけんこう</rt></ruby>大鉄鋪にて逝去した。
<br><br>
修練者は双臂に油を塗り、鉄環を穿入し、運功して双臂を充血堅硬ならしめ、勁を使って木樁を掄打する。木樁を掄断した後は石樁を掄ち、石樁を掄断したら鉄樁を掄つ。万一断つのが手臂であれば、薬膏を塗って好くなるを待ち、また掄ち続ける。久しくしてこれを之くすれば、双手は鉄の如くなる。

## 習得方法

-   2年目崆峒派留学－玄功門入門時に鉄拳門秘笈を選択
-   2年目崆峒派留学－鉄拳門季試一勝
-   2年目10月中旬－[唐惟元](/ja/people/characters/brother4)の物品販売 ($1200)
