# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="2400"></BookItemIcon>

<ruby>李白<rt>りはく</rt></ruby>が中年にして翰林院に仕え、封剣して隠退する前に残した剣法で、全三十六式である。
<br><br>
この剣法は弟子武諤の前でただ一度だけ使われたが、その時李白は酔っていた。
<br><br>
始めは興に任せて振るうようでありながら、至る所に神来の一筆があり、妙を極め、剣のようで剣に非ず、千古の型を破り、未だかつてない奇を開いた。
<br><br>
一套の剣法を使い終えると、樹梢に独り立ち、衣の袂が翻り、宛も神仙の如くであった。一方、座して観ていた武諤は全身汗だくであった。
<br><br>
伝えられるところでは、武諤が難解な箇所を師父に教えを請おうとしたところ、李白は「我に問うな、問えば学べぬぞ」と言った。武諤は猛然と頓悟し、歓天喜地で去ったが、李白が宿酔で誤魔化しただけとは知る由もなかった。

- 太白仙跡：境界二以上、絶招が[太白仙跡]に変化する。四ターンの間、全属性が超幅上昇し、50%の確率で敵の攻撃を回避する。四ターン後に気力が零になる。攻撃コマンドが「舞剣」に変化し、1~3回のダメージを与える。連撃数>10の時、即座に超強大ダメージを追加し、太白仙跡状態を解除する。

## 習得方法

-   [瑞笙来訪](/ja/event/simple/4-02-1-瑞笙來訪)－[瑞笙](/ja/people/characters/special999)の好感度≧40の時、最後に「争いの理由」を選んで話し、別れ際に瑞笙から贈られる（先に盟主になった経緯の話を済ませておく必要がある）。好感度が40未満だと贈られない。
