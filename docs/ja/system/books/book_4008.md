<ruby>丐幇<rt>かいほう</rt></ruby>は蛇を飼い慣らすことに長けている。<ruby>丐幇<rt>かいほう</rt></ruby>の<ruby>蛇形拳<rt>じゃけいけん</rt></ruby>は蛇の形を模倣するだけでなく、本物の愛蛇と共に戦う。拳を出し、脚を出す全てが蛇との連携を必要とし、啄撃、纏繞擒拿の他に隠し技がある。技が熟した時こそが必殺の時――蛇が不意に袖から飛び出して一咬みするのだ！
