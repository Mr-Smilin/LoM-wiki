# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="4003"></BookItemIcon>

伝説によれば、<ruby>峨嵋<rt>がび</rt></ruby>派白猿祖師がある日暇を得て、山中の猿の友を訪ねて遊んでいた際、生涯忘れ得ぬ奇妙な光景に遭遇した。
<br><br>
山猿が小白兎を掴み、蛇が猿の体に絡みつき、鷹が天から降下して蛇を襲い、小白兎が跳び上がって鷹の目を踏みつけた。
<br><br>
この光景は一瞬で過ぎ去り、四獣はいずれも大いに驚いて四散したが、<ruby>白猿祖師<rt>はくえんそし</rt></ruby>だけは呆然と立ち尽くした。帰宅後は茶も飯も喉を通らず、三日目にしてついに悟りを開き、朝食時に卓を叩いて立ち上がり、弟子たちの前でこの<ruby>蛇兎鷹猿搏<rt>じゃとようえんはく</rt></ruby>を披露した。
<br><br>
弟子たちはそれぞれ検証し、資質の高低により悟りに差が生じたが、ただ一人だけが兎形拳を会得した。

## 習得方法

- 2年目の崆峒派留学期間に[夏侯蘭](/ja/people/characters/girl5)に師事し、まず『[つよつよ蹴り](/ja/system/books/book_4002)』を習得してから、3年目の招親イベント後に後山で修練して参拝する。
