# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="8003" />

作者葉雲裳、筆跡はとても美しく、筆鋒には少し子供っぽさがあり、彼女の人となりのようである。<br><br>この書には彼女の雪合戦の技術が書かれており、もっともらしく『正攻』、『奇襲』の二篇に分かれているが、この書の中の技の多くは、彼女が想像したものだ。<br><br>雪玉の中に石や毛虫を隠したり、雪玉を服に入れたりするなど、あらゆる手段を使った残忍な手口が含まれている。
