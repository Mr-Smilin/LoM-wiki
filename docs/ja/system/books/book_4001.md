# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="4001"></BookItemIcon>

<ruby>嵩山<rt>すうざん</rt></ruby>派が<ruby>天下<rt>てんか</rt></ruby>に名を馳せる硬功の一つ。蹴樁功を基礎とし、修練者は両脚に砂袋を括り付け、交互に木杭を百回蹴り上げるのを一回とする。初心者は朝昼晩の一日三回、功力が深まるにつれ一日十回、二十回と増やしていくのが日常となる。
<br><br>
百日を経て砂袋を外せば、脚は軽やかながら勢いは変わらず、基礎が完成する。さらに技巧を練れば、弾、蹬、踹、砸、擺、点、撩、掃の八字腿訣、いずれも足技として自在に繰り出せる。
