# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="2002"></BookItemIcon>

<ruby>福建<rt>ふっけん</rt></ruby>地区で活躍する<ruby>滄幇<rt>そうほう</rt></ruby>弟子が習練する<ruby>武功<rt>ぶこう</rt></ruby>である。
<br><br>
<ruby>滄幇<rt>そうほう</rt></ruby>の背後に<ruby>上官<rt>じょうかん</rt></ruby>世家が控えていることは、誰もが暗黙の了解としている秘密である。この<ruby>翻浪<rt>ほんろう</rt></ruby>刀法すら、<ruby>上官<rt>じょうかん</rt></ruby>家伝来の刀法から演化したものであり、船の櫂や櫓で施展するよう改めたが、かえって隠し切れていない。
<br><br>
この刀法を展開すれば、江上の波濤が汹湧と打ち寄せるが如く、連綿として絶えない。弱者に遇えば陣陣と迫り、強者に遇えば後の手を守る。敵が奮力して抗えば、空を撲つことになり、一旦破綻を露わせば、後浪が咄咄と迫り来る。剛中に柔あり、柔中に剛あり、攻中に守あり、守中に攻あり、極めて上乗な刀法である。
<br><br>
だが君が櫂や櫓で習練すれば、歪んで学ぶことになる。
