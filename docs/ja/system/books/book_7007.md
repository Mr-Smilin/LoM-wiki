# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="7007"></BookItemIcon>

巫山と<ruby>長江<rt>ちょうこう</rt></ruby>流域の交会する鍾乳洞に蔵され、壁上に描かれた神秘の<ruby>武功<rt>ぶこう</rt></ruby>。来歴は不明、何朝を経たかも知れず、九枚の連環図画で修練の法門を演示している。正とも邪ともつかぬ相貌にして、尋常の練功法門に非ず、然れども言簡意賅にして、発聾振聵の効がある。
<br><br>
足を滑らせて落水した漁夫に発見された後、謄拓されて<ruby>朝廷<rt>ちょうてい</rt></ruby>に上納され褒賞を得たが、<ruby>朝廷<rt>ちょうてい</rt></ruby>もこれを重視せず、この<ruby>武功<rt>ぶこう</rt></ruby>は達官貴人の書架の上に埋没することとなった。
<br><br>
その鍾乳洞も水位上昇により、既に徹底的に水没している。

## 入手方法

- 囲城イベント－外出して拳法を練る時の南宮深からの贈呈 (処世≧中庸)
- 3年目4月上旬－[唐惟元](/ja/people/characters/brother4)の買物($1500)

## 備考

- 南宮深からの贈呈時のテキスト：南宮深は君が師長の指導を受けていないことを知り、君が無理に内功を修練することで陰陽が乱れ、身体を傷つけてしまうことを心配しています。そこで君に一冊の内功図録『巫山洞府九宝図』を贈りました。<br>南宮深は謙虚に言うには、この図を学んでも絶世の武功を身につけることはできないが、二儀を調整し、五行を温養することができるだろう、きっと君の役に立つはずだと。実は彼は君がこの図の貴重さを知ったら、簡単に受け取らないだろうと懸念していただけです。
