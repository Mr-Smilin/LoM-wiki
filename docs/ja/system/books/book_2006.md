# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="2006"></BookItemIcon>

この剣法は<ruby>儒家<rt>じゅか</rt></ruby>の孔夫子の手により起草され、騎射の術と共に弟子に伝授された剣術である。その後、孔夫子は列国を周遊し、七国の剣法を網羅して不断に改良精進し、身後も数朝の更迭を経て精益求精、まさに「天行健、<ruby>君子<rt>くんし</rt></ruby>以て自ら強く息まず」の卦象に応じ、剛毅図強、永く息まず。
<br><br>
己を行うに恭しく、争う所なく、適なく、莫なく、大節に臨みて奪うべからず、これを謙仲平和の剣、<ruby>君子<rt>くんし</rt></ruby>の剣と謂う。
