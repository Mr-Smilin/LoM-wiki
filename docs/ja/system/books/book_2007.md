# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="2007"></BookItemIcon>

峨眉がまだ剣派であった時代に遺伝された古老の鍛身法。繁を化して簡となし、大開大闊、剛猛なる処も、峰回路転して余地を留める。
<br><br>
八路の斬法は平凡に見えるが、実は高深な<ruby>武功<rt>ぶこう</rt></ruby>は練り出せないものの、体魄を強健にし、筋骨を伸ばすには助益が大きい。
