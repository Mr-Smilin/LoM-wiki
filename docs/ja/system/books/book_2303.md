# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="2303" />

<ruby>葉雲裳<rt>よううんしょう</rt></ruby>が勝手に<ruby>点蒼<rt>てんそう</rt></ruby><ruby>剣譜<rt>けんぷ</rt></ruby>を塗り替えて創った棒法である。
<br><br>
殺傷力は皆無だが、<ruby>点蒼<rt>てんそう</rt></ruby>剣法の不満足な欠陥を補完し、敵の予想外を突く。招数の変化のみを論ずれば妙手と言えるが、卑怯な点があり、普通の者はこのようなことはしない。
