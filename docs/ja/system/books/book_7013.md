# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="7013"></BookItemIcon>

伝奇の如き前任武林盟主龍淵の成名功夫。実は一套の<ruby>武功<rt>ぶこう</rt></ruby>ではなく、<ruby>龍淵<rt>りゅうえん</rt></ruby>が曾て使った七種の絶技である。
<br><br>
刀剣:<ruby>斬落星辰綱<rt>ざんらくせいしんこう</rt></ruby>、拳掌:<ruby>割山掌<rt>かつざんしょう</rt></ruby>、腿法:<ruby>射日腿<rt>しゃじつたい</rt></ruby>、槍棍:<ruby>小覇王槍<rt>しょうはおうそう</rt></ruby>、長索:<ruby>離奇点穴縄<rt>りきてんけつじょう</rt></ruby>、<ruby>暗器<rt>あんき</rt></ruby>:如意指、<ruby>内功<rt>ないこう</rt></ruby>:玄玄造化功。
<br><br>
当年龍淵は<ruby>群雄<rt>ぐんゆう</rt></ruby>に号令し、旧魔教天堂総壇に攻め入り、<ruby>極楽教主<rt>ごくらくきょうしゅ</rt></ruby>と独闘した。<ruby>斬星射日<rt>ざんせいしゃじつ</rt></ruby>、<ruby>覇王割山<rt>はおうかつざん</rt></ruby>を連番繰り出し、当世正邪両派の高手を震駭せしめ、期せずして皆思った。「これぞ当今天下第一なり」と。

## 備考

- この書は龍淵七絶武功の節録の総集編であり、[龍淵](/ja/people/characters/special2)の個人的な心得の集大成である。
- 他者がこれを得ても、七部武功の根基がなければ習得できないが、[趙活](/ja/people/characters/player)は忘形篇を持っている。
- 斬落星辰綱は一種の剣法で、全真北斗七星陣と関係がある。 [^1]
- 小霸王槍は戦陣の中で悟った槍法で、普通の武功とは全く異なり、大開大闔を用いた戦場での群戦用招数である。 [^1]
- 離奇点穴縄、[玄玄如意指](/ja/system/books/book_4004)は[龍淵](/ja/people/characters/special2)の妻・完顔夢が教えたものである。
- 叙述には玄玄造化功と書かれているが、ゲーム内の対話では鴻蒙造化功である。
- [龍湘](/ja/people/characters/girl8)七絶：斬星射日！霸王割山！玄玄如意... ~~[方少俠](/ja/people/characters/other16)しっかりしろ！殺人だ！白衣の娘さんが殺人を！~~
- 天罡伏魔剣は[龍淵](/ja/people/characters/special2)が七絶武功を融会貫通させた後に悟った最終決戦の奥義である。[^2]
