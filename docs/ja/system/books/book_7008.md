# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="7008"></BookItemIcon>

> 弦を弾くが如く触れ、脈に鳴り響き、その音は久しく衰えません。

習練者は片足で立樁し、脚で<ruby>琵琶<rt>びわ</rt></ruby>を支える。これは<ruby>飛天門<rt>ひてんもん</rt></ruby>「鶴樁」の<ruby>軽功<rt>けいこう</rt></ruby>である。鉄の琴弦を掀き動かすには、まず<ruby>奪魄門<rt>だっぱくもん</rt></ruby>「<ruby>霜刀破竹指<rt>そうとうはちくし</rt></ruby>」を習練せねばならない。さらに音箱を鼓動させるには、<ruby>玄功門<rt>げんこうもん</rt></ruby>の<ruby>内力<rt>ないりょく</rt></ruby>を運使して共振させる必要がある。敵を禦ぐ時は、<ruby>琵琶<rt>びわ</rt></ruby>を抄い上げて武器とし、鉄拳奇門「如意砸」の招数を施展して、敵の頭蓋を打ち砕く。
<br><br>
功成れば心念一動で百脈斉しく鳴り、動けば響弦の如く、歴久不衰、これを<ruby>崆峒<rt>こうどう</rt></ruby>第一神功と為す。

- 鉄琵琶功：<br>
防御で敵の攻撃を受け止めたとき、敵の気を消費させる。<br>
レベル2以上では、攻撃時に敵の気を消費させることができる。<br>
レベル3以上では、攻防時に【衝撃】を与える確率がある（防禦-50%）

## 入手方法

- 囲城イベント－想い人が魏菊の場合、魏菊の招数を受け止めた後に内功治療を受け、崆峒への入門を約束することで獲得（内功≧40が必要）
