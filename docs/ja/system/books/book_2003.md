# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="2003"></BookItemIcon>

一代の<ruby>儒俠<rt>じゅきょう</rt></ruby>、<ruby>曾文先生<rt>そうぶんせんせい</rt></ruby>の著作。四書五経十三経を総括し、<ruby>君子<rt>くんし</rt></ruby>が独を慎むことを論じ、心より体に表れ、知より礼に形となり、不亢不卑、言行一致を説く。月が移り星が変わろうとも、<ruby>江山<rt>こうざん</rt></ruby>が易主しようとも、我は本心を守り、己を修養する。
<br><br>
人間世界がいかに良くとも、我はただ我であるに過ぎず、世道がいかに悪くとも、我はただ我であるに過ぎない。この色身を捨てても、またかくの如し。
<br><br>
およそ我ら剣を練り武を習う者は、本心を守り、剣鋒の両刃を鏡として、問うを恥じず己に求め、謙にして自ら強く息まず、患難に処して憂えず、宴遊に当たりて慮りを惕し、権豪に遇いて懼れなし、これを<ruby>君子<rt>くんし</rt></ruby>の剣となす。
