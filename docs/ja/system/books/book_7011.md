# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="`7011`"></BookItemIcon>

> 成見に囚われず、人の長所を取り入れ、謙虚に自らを戒め、平心静気にして内省する。

<ruby>錦香宮主<rt>きんこうきゅうしゅ</rt></ruby>が苦心惨憺して創制した、<ruby>南宮<rt>なんきゅう</rt></ruby>心法から演化したもので、人の心意を寧定させ、悲切によって身を傷めることのないよう助けることを旨とする。
<br><br>
玄燭とは月を意指し、故にこの功は<ruby>望月<rt>ぼうげつ</rt></ruby>心経とも称される。
<br><br>
人に悲歓離合あり、月に陰晴円缺あり、此の事古より全きこと難し。されど天各一方にあっても、照らすは皆同じ月光である。
<br><br>
慟動の時に当たっては、この功を行い、心神を収斂し、悲傷を力に化して、しっかりと生きるのだ。

## 入手方法

- 🚩虞小梅と結縁 ([虞小梅結縁攻略](/ja/event/pursuit/girl3)参照)。
- [錦香宮見学](/ja/event/simple/3-09-3-參觀錦香宮)で案内役が【🎲＜35 画中仙】。
- [錦香宮イベント集](/ja/event/simple/3-09-3-錦香宮事件集)の自由行動で[画中仙に挑戦](/ja/event/simple/3-09-3-挑戰畫中仙)を選ぶ。
- 画中仙への挑戦に勝利した後、玄燭心経を修める人に👉「自分が修める」を選ぶと入手。<br>

## 備考
- 温夫人がこの玄功を創制したのは、門派の弟子たちが心を落ち着かせ、激情に迷わされず、冷静に判断できるようにするためである。<br>心に障碍がなければ、過去を振り返るとき、思い出がより鮮明になり、心の決意もより揺るがないものになるのだ。
- この功法は本質が陰寒で、心の乱れと火気を調伏できる。
    - [温夫人](/ja/people/characters/special402)は、[唐黙鈴](/ja/people/characters/girl0)の天地無音勢のほうがさらに陰寒で、心を定める力も強いと評している。
    - 龍湘の告白イベントの後、感情が高ぶり心が乱れた[龍湘](/ja/people/characters/girl8)は、最後に玄燭心経で心を静めて落ち着きを取り戻す。
- 錦香宮不伝の秘で、[画中仙](/ja/people/characters/special813)が危険を冒して密かに贈ったもの。
    - [画中仙](/ja/people/characters/special813)の本意は、[虞小梅](/ja/people/characters/girl3)に[焚心火印](/ja/system/books/book_7009)の火蠍の毒を打ち消させ、健康上の危険を取り除くことにあった。
        - ただし玄燭心経を修める代償として[焚心火印](/ja/system/books/book_7009)の効果が打ち消され、[虞小梅](/ja/people/characters/girl3)の功力は弱まる。
    - 男性が修めると体が女性化し、不妊の恐れがあるという。
    - [趙活](/ja/people/characters/player)が[焚心火印](/ja/system/books/book_7009)と玄燭心経を両方修めていると、決闘では実際に[焚心火印](/ja/system/books/book_7009)の効果が失われる。
    - [画中仙](/ja/people/characters/special813)は、[趙活](/ja/people/characters/player)が玄燭心経を修め、[虞小梅](/ja/people/characters/girl3)が趙活に功を伝えて互いに調和させる方法を勧める。火蠍の毒を消しつつ、小梅の今の功力も保てる。
        - 修練を終えた後、陰陽＜40 なら、唐門の後山の修練コマンドに[虞小梅](/ja/people/characters/girl3)と修練するランダムイベントが加わる。イベント後に陰陽+30。
