# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="8002"></BookItemIcon>

<ruby>武穆王<rt>ぶぼくおう</rt></ruby>・<ruby>岳飛<rt>がくひ</rt></ruby>が従軍中に記したものと伝わる。のちに<ruby>孟珙<rt>もうきょう</rt></ruby>が欠けた部分を補い、実戦の例を添えて、ようやくその形と神髄が整った。
<br><br>
謀を定め、事を見極め、攻撃、守備、兵の訓練、将の派遣、布陣、交戦に至るまで漏れがなく、金の戦術に対抗するための策を極め尽くしている。
<br><br>
この書を手にすれば、<ruby>金人<rt>きんじん</rt></ruby>の<ruby>拐子馬<rt>かいしば</rt></ruby>や<ruby>鉄浮屠<rt>てっぷと</rt></ruby>さえ恐れるに足りない、と言い伝えられている。
