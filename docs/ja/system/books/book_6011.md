# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="`6011`" />

奪魄《<ruby>鎮魂功<rt>ちんこんこう</rt></ruby>》、鉄拳《傷拳》、玄功《<ruby>鉄琵琶功<rt>てつびわこう</rt></ruby>》と同じく《<ruby>南岳<rt>なんがく</rt></ruby>真経》より出でた<ruby>飛天門<rt>ひてんもん</rt></ruby>失伝の神通。
<br><br>
飛天脚、仙鶴迷蹤歩の原初の型である。
<br><br>
功成る者は一趾にて立地し、膝を屈して力を使う必要なく、ただ内力を駆使するのみで滑行疾駆できる。足を出す時、勁は身より腿に通じ、腿より脚に通じ、脚より趾に通じ、万鈞の威力を一点に収束する。意念に応じて剛柔自在、剛なれば一趾にて<ruby>金鐘罩<rt>きんしょうとう</rt></ruby>を点破し、柔なれば趾勁をもって人の穴道を封じる。

## 習得方法

v1.0.6001.0 では入手できない。画中仙への挑戦には[虞小梅結縁攻略](/ja/event/pursuit/girl3)のルートに入る必要があるが、小梅ルートでは主人公が必ず崆峒の掌派人になるため、唐門の公開裁判で崆峒派が友好的な態度を示す条件と同時に満たせない。

- 4年目1月下旬、中小門派からの返答のイベントの後半、画中仙 (華仙児) が唐門へ帰ってくる場面で、彼女から贈られる。条件：
    - あなたの決断が西武林盟で、主人公が唐門にいる
    - 武林大会で錦香宮を支持した ([唐門の決断](/ja/event/simple/3-10-2-唐門抉擇))
    - 🚩[画中仙に挑戦](/ja/event/simple/3-09-3-挑戰畫中仙)して決闘した
    - [唐錚](/ja/people/characters/brother2)好感≥40
    - [唐門の公開裁判](/ja/event/simple/3-10-2-公審唐門#崆峒表態)で崆峒派が友好的な態度を示した
