# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="4002"></BookItemIcon>

本来の名は「<ruby>風雷神脚<rt>ふうらいじんきゃく</rt></ruby>」。脚技の使い手として名高い美貌の俠客「<ruby>風神<rt>ふうじん</rt></ruby>」<ruby>[解無塵](/ja/people/characters/special808)<rt>かいむじん</rt></ruby>の成名絶技である。しかし<ruby>餓鬼道<rt>がきどう</rt></ruby><ruby>法王<rt>ほうおう</rt></ruby><ruby>劉顎<rt>りゅうがく</rt></ruby>への挑戦の際、「犯剣」によって衆人環視の中で辱めを受け、<ruby>[解無塵](/ja/people/characters/special808)<rt>かいむじん</rt></ruby>は怒りのあまり血を吐いて敗北。約定により「<ruby>風雷神脚<rt>ふうらいじんきゃく</rt></ruby>」を「つよつよ蹴り」と改名せざるを得なくなった。
<br><br>
「つよつよ蹴り」は極めて鋭利で、速度は迅猛、風雷を呼び起こすが如し。山岩を蹴り裂き、向かうところ敵なし、実に恐るべき威力を持つ。

## 習得方法

- 囲城事件――丐幇優勢で、宿屋から撤退(戦術 LV0が必要)する際に丐幇に遭遇し、風神に救援されて、1000銀両を支払って習得。
- 2年目に崆峒派へ留学し、[夏侯蘭](/ja/people/characters/girl5)に師事、3年目の招親の後、後山で修行して祭祀を行う。
