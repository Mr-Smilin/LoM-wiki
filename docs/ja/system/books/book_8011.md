# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="8011" />

<ruby>火炎山剣閣<rt>かえんざんけんかく</rt></ruby>の各種兵器、鉄器の型録であるだけでなく、秘して宣さぬ鍛冶の奥秘も含まれている。<br><br>書中には異なる金属と合金の特性、配方が記録され、火炎山の地熱を利用した退火、淬火、回火などの工芸が記されている。<br><br>あなたが熟知する<ruby>唐門<rt>とうもん</rt></ruby>鍛法と比較すると、より正統で厳謹である。
