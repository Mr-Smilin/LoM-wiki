## 習得方法

- [四師兄、商いの長旅へ](/ja/event/detailed_description/3-08-1-四師兄遠遊經商)の別れの時、「あえて難題を突きつける」を選び、ダイスで【≧70 さあ、地元の土産品だな】を出し、さらに「華山には仙人がいると聞いた、仙人は霊丹を持つ」を選ぶ。
- 3年目11月上旬の[門人の暇乞い-四師兄が帰る](/ja/event/simple/3-11-1-門人辭別#四師兄歸來)の後、男弟子房の[四師兄との雑談](/ja/event/simple/0-0-0-四師兄閒聊)で「前に頼んだ調べ事」を選ぶ。
- 銀両≥5000、[唐惟元](/ja/people/characters/brother4)好感≥50で、「買う」を選ぶと入手。
