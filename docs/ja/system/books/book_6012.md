# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="`6012`" />

<ruby>唐門<rt>とうもん</rt></ruby>女俠唐芬が<ruby>青城<rt>せいじょう</rt></ruby>《<ruby>八仙剣法<rt>はっせんけんぽう</rt></ruby>》の<ruby>五行<rt>ごぎょう</rt></ruby>学説に基づき、五毒をもってこれに替え、創成した独門武功。
<br><br>
招式を論ずれば多くとも二流だが、<ruby>唐門<rt>とうもん</rt></ruby>の医、毒二術を隠含し、十分艱渋で読み難く、読んだとしても大した成就を得られるとは限らない。
