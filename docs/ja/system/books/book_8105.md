# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="8105" />

<ruby>魏菊<rt>ぎきく</rt></ruby>が精選した当代傑出文人の詞集で、<ruby>宋詞<rt>そうし</rt></ruby>百闋を節録し、平理は衡の如く、照辞は鏡の如し。<br><br>収録されたものは必ずしも名家の筆によるものではないが、必ず傑作である。<br><br>この書は<ruby>魏菊<rt>ぎきく</rt></ruby>の手写しで、字跡は娟秀、美女の<ruby>簪<rt>かんざし</rt></ruby>花の如く、また鸞飄鳳泊の如く、鬱々として志を得ざる様である。およそ文人雅士でこの冊を見て欣喜雀躍せぬ者はいないが、ただあなたというこの<ruby>江湖<rt>こうこ</rt></ruby>の人にのみ贈られた。<br><br>彼女は誓約を謹守しつつも、少しの私心を隠し、「佚名」の身分で、密かに自身の旧作を収録した。
