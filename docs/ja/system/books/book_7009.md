# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="7009"></BookItemIcon>

<ruby>飛天門<rt>ひてんもん</rt></ruby>と<ruby>奪魄門<rt>だっぱくもん</rt></ruby>が<ruby>崆峒<rt>こうどう</rt></ruby>の門面を争う際、速成を求めて、鴆を飲んで渇を止めるが如く、火蠍の毒で<ruby>内力<rt>ないりょく</rt></ruby>を助長し、強引に瓶頸を突破した。
<br><br>
<ruby>焚心火印<rt>ふんしんかいん</rt></ruby>を運使すれば、暫時心搏を加速し、血流を推動できる。余寿を燃焼する代価として、肉体能力を全面的に向上させる。
<br><br>
しかし代価はこれだけではない。火毒が体内に囤積し、鼎盛に達する度に表徴に溢れ出る。軽ければ口乾舌燥、歯齦からの滲血、失眠易怒、重ければ火気が脳を衝き、痴呆か暴斃かのいずれかとなる。
<br><br>
毎年端午の陽気最盛の時は尤も凶険であり、慎まざるべからず。

## 入手方法

-   2年目崆峒派留学－飛天門の[崆峒派季期試験](/ja/event/simple/2-05-3-崆峒季試)三勝報酬（[虞小梅](/ja/people/characters/girl3)好感度≧20）
-   🚧未実装：3年目招親－飛天門留学、[金烏上人](/ja/people/characters/special207)に勝利、[顔疆](/ja/people/characters/trainee204)死亡時に贈呈。台本にはこの場面があるが、現行版は判定条件の設定が誤っていて、実際には[仙鶴迷蹤拳](/ja/system/books/book_6003)しか手に入らない。

## 備考

-   飛天門の秘奥。
-   焚心火印はもともと光明正大で、心を平たく静かに保ち、着実に修練すれば、暑気を吸収し、臓腑を鍛錬し、日が経てば自ずと功が成る。
-   飛天奪魄両門の争いが激烈なため、飛天門の先輩が速成法門を創出し、火蠍の毒を服用して無理やり熱力を促進させ、臓腑を傷つけた。大関を乗り切って死を免れれば、功が成る。
-   しかしこの方法で修練する弟子の十に八九は短命で早死にする。
-   [玄燭心経](/ja/system/books/book_7011)を修め終えていると、焚心火印の属性が陽であっても効果を失う。

### 虞小梅との関わり

-   [趙活](/ja/people/characters/player)が飛天門の季試で焚心火印を得ると、小梅は焚心火印を修めないよう諭し、その危険と代償、そして[火龍仙君](/ja/people/characters/special204)の本当の狙いを打ち明ける。
-   小梅は天賦が卓越しており、暴斃で死ぬことなく、[火龍仙君](/ja/people/characters/special204)が運功で火力を疏導してくれたので、最終的に功が大成した。
    -   ただ臓腑は既に傷んでいるため、後患が無窮で、毎回運功する際も心が焦り焚け、劇痛に耐えられず、遠くは寿を縮め、近くは暴斃の危険があるため、全く実戦には使えない。そのため[虞小梅](/ja/people/characters/girl3)は人と交手する際も、焚心火印を運用することはない。
    -   唐布衣の暗殺イベントでは、小梅（女飛賊）が[趙活](/ja/people/characters/player)を相手にするとき、珍しく焚心火印を実戦で運用する。
    -   小梅が焚心火印を修めたのは、功力を早く高めるためだけでなく、焚心火印で屍心丹の毒虫を滅ぼせると期待したからでもある。後者は叶わなかった。
    -   錦香宮を訪れている間、[画中仙](/ja/people/characters/special813)が危険を冒して密かに[玄燭心経](/ja/system/books/book_7011)を贈り、小梅が火蠍の毒を打ち消せるよう願う。
-   掌派争奪戦の間、小梅は半雨屏の向かいの山の高い木の上で焚心火印を運用し、烈焔飛天脚と合わせて飛び降り、[金烏上人](/ja/people/characters/special207)と相討ちになろうとする。
    -   しかし奪魄掌門に阻まれ、屍心丹に心を支配されてしまう。
