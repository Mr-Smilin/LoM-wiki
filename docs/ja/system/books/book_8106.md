# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="8106" />

翰林医官が太宗皇帝の詔令を奉じて編纂した医書である。<br><br>診法、処方用薬、五臓諸病、内科、外科、婦人科、小児科、服食、丹薬、外益、針灸などの内容を包括する。[^1]<br><br>原典は百冊に及ぶが、あなたが得たものは綱目のみである。なぜなら<ruby>二師兄<rt>にしけい</rt></ruby>は、省略した内容は常識であり、あなたは知っているべきだと考えたからである。
