# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="3000"></BookItemIcon>

<ruby>嵩山寺<rt>すうざんじ</rt></ruby>の僧は禅修苦行において、三不善根を断つ必要がある。貪、瞋、癡は世間一切の煩悩の根本であり、煩悩は人を駆り立てて種々の悪業を造らせる。
<br><br>
<ruby>解脱<rt>げだつ</rt></ruby>を得んとするには、五蘊を了知し、顛倒夢想を遠離し、方に究竟涅槃を得られる。
<br><br>
しかし大道はここにあれど、世にこれを成し得る者が幾人いようか。
<br><br>
この時、<ruby>苦悩拳<rt>くのうけん</rt></ruby>は良善なる対症療法となる。拳を練り汗を揮い、疲れ果てれば、自然と妄想する力も失せるのである。
