# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="8104" />

<ruby>唐門<rt>とうもん</rt></ruby>に代々伝わる医書で、当世唯一の毒を用いた医術書である。<br><br><ruby>苗疆<rt>びょうきょう</rt></ruby>や仏家の学説を融合し、一碗の水に八万四千の虫がいると説く。虫すなわち毒であり、<ruby>五行<rt>ごぎょう</rt></ruby>六合に分かれ、五臓六腑に対応する。多ければ害となり、少なければ病となり、尽きれば虚となり、誤れば狂となる。<br><br>人は五毒に害されないのではなく、実は毒性が未発なだけである。ただ薬を用いてこれを養い、心に順い逆らわせず、毒を己が用に転じれば、百病も侵し難くなる。
