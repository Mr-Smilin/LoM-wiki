# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="4040"></BookItemIcon>

阿摩の二字が究竟何を意味するのか、誰も知らない。<ruby>丐幇<rt>かいほう</rt></ruby>伝功長老も、<ruby>耕陽読書齋<rt>こうようどくしょさい</rt></ruby>のあの生き字引たちでさえ知らない。
<br><br>
しかし搪牆の意味は「塗抹」と解釈されている。換言すれば、この拳法は極めて狭小な空間でこそ最大の功効を発揮する<ruby>武功<rt>ぶこう</rt></ruby>である。敵を壁に押し付けて死命を打ち、肉醤として壁に塗抹する。
<br><br>
理念は単純だが、この<ruby>武功<rt>ぶこう</rt></ruby>は外功の底がなければ成立しない。寸勁、頓肘、鉄山靠、全てが実打実の実戦功夫である。
