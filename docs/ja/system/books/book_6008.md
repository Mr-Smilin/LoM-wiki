# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="6008"></BookItemIcon>

あなたが<ruby>唐門<rt>とうもん</rt></ruby><ruby>大師兄<rt>だいしけい</rt></ruby>、登徒子が己の行状より編み出した<ruby>武功<rt>ぶこう</rt></ruby>で、登雲梯続集に収録されている。
<br><br>
美人に会わんがため雲に登り楼台に至る。その中の踏月式はこの<ruby>軽功<rt>けいこう</rt></ruby>より派生した攻招である。「月」は光輝を指し、暗に己に向けられた全ての兵刃を喩える。
<br><br>
故に踏月式の真義は、専ら他人の兵刃を踏みつけ、高所より人の顔面を踏みつけることにある。

## 習得方法

-   2年目崆峒派留学で[夏侯蘭](/ja/people/characters/girl5)に師事時、奪魄森林で修行。師父の不機嫌が累積2回後に[唐布衣](/ja/people/characters/brother1)についての話が出て、再び森に入り、会話で大師兄を話題に選ぶと習得。

## 備考

-   [夏侯蘭](/ja/people/characters/girl5)が著した、[唐布衣](/ja/people/characters/brother1)の『登雲踏』と雪山派の『梅梢望月歩』を融合させたもの。
