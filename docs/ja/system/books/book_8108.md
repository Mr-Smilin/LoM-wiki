古今に流行する折紙の方案を収録し、紙箱、紙船、紙蛙、紙鶴、紙魚、紙花、紙剣から紙の雲梯に至る。<br><br>画工は細膩で、解説は明晰、この書があれば、誰でも折紙戦士になれる。

## 入手方法

- 留学せず、廃寺ルートで唐門に通報し、講経堂のダイスで【折紙集】を入手する。

## 備考

- [掌門](/ja/people/characters/master)こと唐中翎が[四師兄](/ja/people/characters/brother4)こと唐惟元に託し、[小師妹](/ja/people/characters/girl0)こと唐黙鈴に贈った秘笈である。
- 唐黙鈴は大喜びで本に載っているものを片っ端から折ったが、色紙がなくなると悪知恵を働かせて秘笈の紙まで折ってしまい、表紙だけを床下に隠した。自分の秘笈を折り終えると他人の秘笈にまで手を出したため、やがて露見して掌門の家法で罰せられ、本も封印された。
- 『摺紙戦士』は台湾の漫画家・周顕宗による漫画作品である。
