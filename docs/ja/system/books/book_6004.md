# {{ $frontmatter.title }}

<BookItemIcon :size="`medium`" :needLink="false" :no="6004"></BookItemIcon>

かつて名を一時に動かした怪盗鉄面人が独創した爪功。
<br><br>
正理に循わず、剣走偏鋒し、昏冥に潜み、影と化し、黒夜に遁入し、致命の一撃を施す。
<br><br>
鉄面人は龐太師の命を受け、包拯を襲殺せんとしたが、包公の鉄面無私なる気魄に心折れ、私を以て青天を戕害するを願わず、されど背信も敢えてせず。遂に自ら優勢を捨て、暗中より行出し、南俠展昭に請戦し、<ruby>光明<rt>こうみょう</rt></ruby>正大に敗れ、自ら十指を断ち、包拯は遂に死罪を赦免した。
<br><br>
鉄面人は<ruby>崆峒<rt>こうどう</rt></ruby>に帰隠し、人に<ruby>鉄爪<rt>てっそう</rt></ruby>義手を鋳造させ、この書を著した。
