# {{ $frontmatter.title }}

## 概要 {#簡介}

- [唐惟元](/ja/people/characters/brother4) (四師兄) が崆峒派から持ち帰った、からくり仕掛けの弾珠台。もとは[郁竹](/ja/people/characters/girl6)が崆峒の夜市に置いて、子どもに1回1文で遊ばせていた玩具。
- 最初は「四師兄の押し売り」で無料で試遊する。以後は唐惟元に話しかけると遊べる (1回 銀両200)。
- 3局の合計点で景品が決まる。同じ等の景品でも、もらうたびに中身が変わる。

## 四師兄の押し売り {#四師兄兜售}

| 発生条件 |
|---|
| 1年目5月上旬〜2年目12月下旬 (昼) |
| 唐惟元と主人公が唐門にいる |
| 店での累計購入額が銀両5000以上 |

崆峒から戻った唐惟元が、崆峒で仕入れた古道具を同門に売りつけようとする。

1. 飛天門の高手が履いていたという「飛天鞋」
    - 👉「うえっ、他人のお古」: 処世+1、品性-1、弁舌+1、唐惟元-1
    - 👉「ノーコメント」: なし
2. 玄功門の弟子が鉄琵琶を弾くときの鉄の指当て: 1で「うえっ、他人のお古」を選んだ場合だけ、同じ選択肢がもう一度出る。効果は1と同じ。
3. 2回とも「うえっ、他人のお古」を選んだ場合: 弁舌+1、唐惟元-1
4. 道徳<40: 品性-1、弁舌+1
5. 唐惟元が代わりに弾珠台を出して試遊を勧める
    - 👉「とぼけるな、何か企んでるだろ」: 性情-1
    - 👉「じゃあ遊んでみるか」: なし
6. ルール説明 (👉「もう一回説明して」で聞き直せる) のあと、試遊を1ゲーム遊ぶ。
    - 試遊なので景品はもらえない。終わると弾珠台が解放され、以後は唐惟元に話しかけて遊べる。
    - 試遊で台を揺らして壊した場合は[台を壊したとき](#弄壞彈珠台)へ。

## 遊び方 {#玩法}

- 1ゲーム3局、1局8球。
- 長押しで力を溜め、離すと球を打ち出す。
- 下に穴が8つある。点数は左から 3・2・1・1・1・1・2・3。
- 1局のうちに同じ穴へ4球目が入ると、その穴の点数の10倍を加算する (3点の穴なら+30)。5球目以降は通常の点数だけ。
- 1局の8球を8つの穴に1球ずつ入れると、+150。この1局だけで 14+150=164点になり、大賞の100点を超える。
- 3局の点数の合計で景品が決まる。

### 台を揺らす {#搖晃彈珠台}

- 台を揺らすことができる。揺らした回数は1ゲームを通して数える。
- 3回目ごとにピンが落ちる (3回目に1本、6回目に2本、9回目に3本…)。
- 5回目ごとに、穴と穴を仕切る柱が1本ランダムに折れる。1本につき-5点。
- 柱が折れると、その柱の左隣の穴と、さらにその左の穴では、そのゲームのあいだ「4球目で10倍」が出なくなる。「8つの穴に1球ずつ」の+150も取れなくなる。
- 柱は7本ある。35回目に7本目が折れると台が壊れ、景品はもらえない。

## 景品 {#獎品}

| 遊べる条件 |
|---|
| 弾珠台が解放済み (試遊を済ませた) |
| 銀両200以上 |
| 唐惟元と主人公が唐門にいる |

1回遊ぶごとに銀両-200。景品をもらった回数は等ごとに数える。

| 合計点 | 1回目 | 2回目 | 3回目以降 |
|---|---|---|---|
| 大賞 (100点以上) | [外号](#大獎外號)、名声+3 | 名声+2、青城派・全真教・峨嵋派・崆峒派・嵩山派・点蒼派の門派好感度+1 | 2回目と同じ |
| 二等賞 (60〜99点) | 秘笈『梅郷清供』 | 磨喝楽 紅 | 郁竹が唐門にいる: 小竹の手伝い券 (1回だけ)<br>それ以外: 甘蔗×3 |
| 三等賞 (30〜59点) | 秘笈『手写しの全真剣法』 | 磨喝楽 緑 | 郁竹が唐門にいる: 小竹の手伝い券 (1回だけ)<br>それ以外: 甘蔗×2 |
| はずれ (29点以下) | 甘蔗×1、唐惟元+1 | 同左 | 同左 |

### 大賞の外号 {#大獎外號}

1回目の大賞では、唐惟元が金を出して人を雇い、あなたの外号を広めてくれる。外号は天運ダイスで決まり、どれでも名声+3。

- 【🎲<40 じゃあ何かいい案でもあるのか？（怒）】
    - 性情<60: 外号「なんでもいい」
    - 性情≥60: 外号「鋼珠」
- 【🎲<75 弾珠侠で決まり、文句言うな】: 外号「弾珠侠」
- 【🎲≥75 まともな外号】: 外号「弾星手」、心相-10

2回目以降の大賞では、唐惟元が行商先で武林の先達にあなたの名前を売り込んでくれる。

## 台を壊したとき {#弄壞彈珠台}

台が壊れると景品はもらえない。その後の展開は、郁竹が唐門にいるかどうかで変わる。

### 郁竹が唐門にいない (試遊で壊した場合も) {#郁竹不在唐門}

唐惟元-3、品性-3、処世+2。唐惟元に弁償を迫られる。

- 👉「弁償する」(銀両1000以上で選べる): 銀両-1000、品性+1、唐惟元+3
- 👉「払う金がない」: 貢献度-50 (掌門の裁きで、唐惟元の店番を代わりに務めて借りを返す)

### 弾珠台の修理 {#修理彈珠檯}

郁竹が唐門にいるとき、最初に台を壊すと郁竹に相談に行く。郁竹は、これは自分が作った弾子台だと気づいて直してくれる。数値の変化はない。

郁竹によると、崆峒の夜市にこの台を置いて子どもに1回1文で遊ばせていたが、うまく遊べなかった子どもたちに「詐欺だ」と奪魄門へ訴えられ、屋台を閉めさせられたという。

### 2回目以降に壊したとき {#之後再弄壞}

郁竹はまた直してくれるが、好感度が下がる。

- 処世≥60: 郁竹-1、弁舌+1、品性-1
- 修理のあと最初に壊したとき: 郁竹-1
- それ以降: 郁竹-3
