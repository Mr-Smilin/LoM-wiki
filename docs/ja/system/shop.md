# {{ $frontmatter.title }}

## 概要 {#簡介}

- [唐惟元](/ja/people/characters/brother4)(四師兄)の商店。秘笈・酒・茶・食べ物・色紙・江湖快報を売っている。
- 毎月上旬に品揃えが入れ替わり、数もこのとき補充される。
- すでに持っている秘笈は並ばなくなる。
- 茶・酒・食べ物は買ったその場で飲食できる。[唐惟元の商店仕組み](/ja/other/guide/mechanism/brother4-selling)を参照。

## 入り方 {#入口}

1. [四師兄との雑談](/ja/event/simple/0-0-0-四師兄閒聊): 男弟子房で四師兄と雑談し、「物品売買」を選ぶ。四師兄が唐門にいない期間は会えない。
2. [四師兄、商いの長旅へ](/ja/event/detailed_description/3-08-1-四師兄遠遊經商): 3年目8月上旬の唐門の会議で「あえて難題を突きつける」を選び、ダイスで【＜70】感謝還元大セールが出ると店が開く。商品は半額。
3. 崆峒留学: [無色市集](/ja/people/factions/kong-tong-sect#無色市集)で街を歩くと、四師兄に会えることがある。唐惟元好感≥20 だと会いやすい。
4. [四師兄の青城訪問](/ja/event/simple/2-10-1-四師兄訪青城): 青城留学ルートで、2年目10月上旬に唐惟元好感≥30 だと発生する。「買う」を選ぶ。
5. [江陵囲城](/ja/event/simple/2-09-1-江陵圍城): 自由行動で「四師兄(商店)」を選ぶ。

## 価格 {#價格}

- 買値＝定価×(1－唐惟元好感÷200)、四捨五入。好感が 1 上がるごとに 0.5% 安くなり、好感 100 で半額になる。
- [四師兄、商いの長旅へ](/ja/event/detailed_description/3-08-1-四師兄遠遊經商)の「感謝還元大セール」から入ったときは、すべて半額。
- 店を出るたびに、店で売買した累計金額 1000 ごとに唐惟元好感+1。節約したいなら分けて買うとよい: 1000 買うごとに店を出て入り直すと、先に好感が上がり、そのあと買う品が安くなる。
- 四師兄に売れるのは道具だけで、売値は定価の 4 割。秘笈と江湖快報は売れない。
