# {{ $frontmatter.title }}

次回、金烏上人死す！ このページには、これまでに分かっている金烏上人の死亡条件をすべて集めた。豚を屠ろうと刀を研ぐ趙活たちのためのページである。

<br>

[金烏上人](/ja/people/characters/special207)が死ぬのは、次の3か所だけである。<Girl0Icon>小師妹</Girl0Icon>の比武招親の夜に死なず、金烏事変も起きなかった場合、第3年7月上旬に金烏上人は崆峒派の掌派人になる。

## 小師妹の比武招親 {#小師妹招親}

第3年5月上旬、<Girl0Icon>小師妹</Girl0Icon>の比武招親の夜。

1. [金烏の騒動](/ja/event/simple/3-05-1-金烏鬧事)で「決闘」を選ぶか、「武徳を度外視し集団で殴る」の後で金烏を追いかけ、[金烏との決闘](/ja/event/simple/3-05-1-對決金烏)の **🆚 決闘：金烏と一対一** に勝つ必要がある。負けると金烏は生き残る。
2. [金烏の死んだふりを見た](#見過金烏詐死)ことが必要。見ていないと、金烏は負けたふりをして不意打ちし、逃げてしまう。
3. 小竹の帰郷が起きていた場合 ([郁竹結縁攻略](/ja/event/pursuit/girl6)・[虞小梅結縁攻略](/ja/event/pursuit/girl3)の流れではたいてい起きる)：金烏は郁城を盾にし、毒煙をまいて逃げるので、ここでは死なない。ただし、その後の[金烏事変](#金烏事變)で殺す機会がある。
   + v1.0.6000.5 の不具合：余公子のイベントは起きたが小竹の家について行かなかった場合も、知り合っていないはずの郁城が話に出てくる。
4. 小竹の帰郷が起きていない場合：
   + <Girl0Icon>小師妹</Girl0Icon>が参戦する (想い人が<Girl0Icon>小師妹</Girl0Icon>かつ<Girl0Icon>唐黙鈴</Girl0Icon>の好感度≧50)：**🎲天命：阻止......** の結果にかかわらず、金烏は死ぬ。
   + <Girl0Icon>小師妹</Girl0Icon>が参戦しない：**🎲天命：阻止......**(上限50、➕加値：軽功、性情) で **🧾【≧70】逃さない** が出たときだけ死ぬ。**🧾【＜70】金烏上人の逃亡** なら生き残る。
5. ここで金烏が死ぬと、<AchievementIcon :size="`small`" :no="`01`">師門の柱石</AchievementIcon>も解放される。

### 金烏の死んだふりを見た {#見過金烏詐死}

第3年1月の[飛侠の帰還](/ja/event/detailed_description/4-02-2-飛俠歸來)で、金烏の死んだふりを見られるのは次の場合だけである。

+ [唐布衣](/ja/people/characters/brother1)と一緒に下山する ([帰路での襲撃](/ja/event/simple/3-01-3-回程遇刺))：**🎲天命：君の対手......** で金烏上人が出る (勝敗は問わない)、または<Girl3Icon>虞小梅</Girl3Icon> (女盗賊) に勝つ。
+ 唐門に残る ([大師兄の重傷](/ja/event/simple/3-01-3-大師兄重傷))：<Girl3Icon>虞小梅</Girl3Icon>が唐門にいない状態で、大師兄の治療中に **📖選択：やめる** を選び、その後 **📖選択：挑む** を選んで金烏上人に勝つ。

### 恩讐の果て {#恩仇的盡頭}

<Girl5Icon>夏侯蘭</Girl5Icon>に弟子入りしていると、[金烏の騒動](/ja/event/simple/3-05-1-金烏鬧事)で集団で殴りかかって負けた後、崆峒へ攻め上る。金烏上人に勝つと<EndIcon no="22">汗青書22</EndIcon>に進む。詳しくは[恩讐の果て](/ja/event/simple/3-05-1-恩仇盡頭)を参照。

## 金烏事変 {#金烏事變}

第3年5月、崆峒。

1. [金烏との決闘](/ja/event/simple/3-05-1-對決金烏)の初戦に勝ったが金烏に逃げられ (死んだふりを見ていない場合は、葉雲舟が不意打ちを防ぐか、自分でかわす必要がある)、小竹の帰郷が起きていて、<Girl0Icon>小師妹</Girl0Icon>が参戦していないとき、☯郁城の頼み に続く。
   + 小師妹が参戦した場合は、戦いの後すぐに小師妹を山へ送り返すので、☯郁城の頼み は起きない。
2. 想い人が<Girl3Icon>虞小梅</Girl3Icon>で襄陽行を経験している、または想い人が<Girl6Icon>郁竹</Girl6Icon>で小竹を受け入れたことがある場合に、**📖選択：行かなくては** を選んで崆峒へ向かう。
   + それ以外の場合や、**📖選択：それもそうだ** を選んだ場合、金烏は生き残る。
3. 金烏事変では、金烏は必ず死ぬ。

## 東西武林盟会戦 {#東西武林盟會戰}

第4年2月中旬、西武林盟ルート。詳しくは[東西武林盟会戦の唐門大院防守ルート](/ja/event/detailed_description/4-02-2-東西武林盟會戰#_3-1、唐門大院防守ルート)を参照。

1. **📜議題：(事件)決闘：三師兄を護衛する** を選ぶ。
2. **🎲天命：二人目の刺客は......** で **🧾【＜33】下心ある陰謀家** が出たとき、金烏が生きていれば金烏が出てくる。
3. 勝った後は、どの選択肢を選んでも、<Girl3Icon>虞小梅</Girl3Icon>が金烏の首を斬り落とす。
