# {{ $frontmatter.title }}

全真七子の一人「太古真人」郝大通。老荘と易経に精通し、卜筮占卦を得意とする。華山に奇遇ありと占い、果たして希夷祖師の《睡功》を手に入れた。以後悟るところがあり、全真華山派を開いた。
<br><br>
二十数年前に[青城論道](/ja/event/stories/青城論道)へ参加し、[鄒博](/ja/people/characters/special201)と意気投合した。

## 史実の郝大通
- 郝大通は、名は璘、字は太古、号は大通、道号は恬然子、またの号を広寧子といい、太古道人と自称した。
- 道教全真道の著名な道士であり、全真七子の一人。
- 1140年1月24日に生まれ、1213年1月23日に没した。
- 老荘と易経に精通し、卜筮占卦を得意とした。大定七年丁亥（1167年）秋に王重陽に師事して全真教に帰依し、数年後に同教の掌門人を継いだ。
- 全真教華山派を開き、道教符籙派と密接な関係を持った。
- 金の崇慶元年壬申臘月晦日（1213年1月23日）、寧海の先天観にて坐化した。
    - 羽化帰天の後、元の世祖より「広寧通玄太古真人」に封じられ、元の武宗より「広寧通玄妙極太古真君」を加封された。
- 台湾の一部の道教廟では今も旧暦正月三日に郝大通を祀り、「太古真人聖誕」と称している。
